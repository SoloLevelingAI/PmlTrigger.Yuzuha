# 持久化窗口布局与停靠预览

## Why
辅助工具浮动后，重启应恢复位置、大小和停靠状态。拖回时需要看得清楚的停靠目标，避免松手后才知道布局结果。

## What Changes
- 先扩展 FigCraft：半透明停靠内容范围、目标页签高亮、松手提示及重启恢复状态。
- 本机保存主窗口、打开的辅助工具、浮动/停靠状态和浮动几何，启动恢复。
- 拖动时实时预览，松手停靠，移出目标隐藏预览；预览不拦截输入。
- 显示器/工作区变化时修正不可见几何，损坏配置回退并留备份。
- 布局是前端配置，不写入 UIC 项目或后端业务记录。

## Impact
WPF 增加布局 JSON、恢复流程、Windows 消息下的拖动预览与跨进程原生验证；保持后端和 HTTP 契约不变。
