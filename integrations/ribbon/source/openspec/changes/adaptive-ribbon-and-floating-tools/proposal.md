# 自适应工作区、可折叠 Ribbon 与独立浮动工具窗

## Why
0.10 已把主视角恢复到 Office 式 Ribbon，但窗口仍按固定宽度排布：左右侧栏宽度写死，Ribbon 始终占 106 px，底部三页工具只能靠「放大停靠区」硬撑；把停靠页拖出后得到的窗仍是底部小面板的放大版，带着工具标题、嵌套大标题和拖出条三层壳。用户要求：侧栏能拉伸/缩短，在不损失文字与图标精度的前提下尽量压缩页面，Ribbon 能折叠，拖出的辅助窗必须是独立界面。

第一轮复核又澄清了几件硬要求：**顶部命令 Ribbon 必须在正常与紧凑两种默认态都完整展开**，手动收起是表格编辑的常见工况而不是窄屏补救；收起与展开必须同尺寸往返，不能点收起就把 1280 窗口变成 1100。中央 UIC Ribbon 预览必须常驻，小按钮每列最多 3 行，采用实际 YtoolsAM 的 13 个按钮；表格行内文字、图标与勾选框统一按整行垂直居中；颜色回到 0.5/0.10 的轻盈 Office 基调，去掉深蓝外描边、厚阴影、发光与发黑的外部背景。

## What Changes
- 新增 FigCraft 设计页「0.11 自适应工作区与浮动窗」，保留原页面、原真图标资产与原原型；只改新增页，18,162 个原图层 ID 与 11 张原图不变。
- 主窗四个状态：1280×800 展开（默认）、1100×740 展开（紧凑默认）、1280×800 手动收起、1100×740 手动收起；收起与展开**同尺寸往返**，收起只把 62 px 还给表格。
- 左右侧栏可拖动（6 px 分隔条）并可收起为 48 px 竖轨；宽度范围统一为左 148–320（默认 232 / 紧凑 168）、右 216–380（默认 300 / 紧凑 246）、中央最小 480。
- 顶部命令 Ribbon：展开 106 px 保留文件 / 设计 / 撤销·重做 / 工具四组 14 个命令入口（不压成文字菜单）；收起 44 px 保留页签、5 个常用命令与常驻「展开 Ribbon」，Ctrl+F1 同步。旧布局无折叠字段时默认展开，手动收起可重启恢复。
- 中央 UIC 预览改为 YtoolsAM 实际 **13 个按钮 / 3 Group**，每列最多 3 个、超出另起新列、组标题底部对齐；删除凭空添加的「通用工具箱」「打开工具箱」等按钮与「16 · 32」占位小字。
- 表格行内名称与 Group 副行作为整体居中，Macro / Tooltip 单行对齐行中心，图标与勾选框按行中心对齐；计数统一为 13 并按「显示 N / 13 项」表述。
- 三个浮动窗改为独立界面（按钮/查找 980×680、UIC↔XML 1024×680、部署 1024×720），壳更轻：细边 + 极浅投影，去掉帧级大阴影；查找窗作用域与结果一致（当前 UIC 可批量，跨文件只读）；只勾选行未选字段时主按钮为「批量设置 3 项」；UIC↔XML 明确登记对象是 UIC 文件而非按钮。
- 视觉回到轻盈 Office：白底、浅灰分区、淡灰细线、低饱和选中、少量蓝色强调、保留窄蓝标题栏；原 UIC 图标不染色。
- 导出 1×/2× 主窗四态、侧栏折叠、三个浮动窗、停靠预览与状态说明，并补充 README 与 OpenSpec。
- WPF / 后端保持未实施；不改真实 UIC / XML，不提交 git。

## Impact
- 仅影响设计资产：`design/figcraft/ribbon-adaptive-workspace-0.11.figcraft`、`design/figcraft/adaptive-0.11/` 与 `openspec/changes/adaptive-ribbon-and-floating-tools/`。
- 原设计源 `ribbon-first-docked.figcraft` 及其页面、组件、图标、原型未被修改；未写真实 UIC/XML，未改动 WPF、后端或其他项目。
- WPF 与后端实施留待设计确认后单独进行；前后端独立架构、HTTP 契约与业务语义不变。预期 WPF 侧改动集中在视图承载（可折叠 Ribbon、可拖动侧栏、浮动窗容器）、表格行模板与布局 schema 的字段扩展，不需要新的业务接口。
