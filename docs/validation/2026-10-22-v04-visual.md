继续使用现有 C# 会话发现和启动身份核验、函数注册表与人工许可、RPC 桥、PMLFORMS / FMSYS、有界读取、LaunchService、PluginDeployment、RuntimeJournal，以及 LaunchDesk 的 test-map / DocFX / 按 ID 执行器。
