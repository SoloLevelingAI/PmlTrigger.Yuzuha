# 安装与环境准备

从工作台的“安装与环境准备”进入。阶段名称表示当前阅读位置；每次实际操作都以本次回执判断结果。

<a id="install"></a>

## 1. 安装交接

使用正式安装器完成应用安装后，核对工作台显示的工具包位置和版本。交接核验读取已安装文件和所有权信息；应用文件安装完成后，继续准备所选 AVEVA 环境。

静默安装后可以手工打开工作台。交接参数只用于定位工具包，不授予环境写入或启动权限。

<a id="environment"></a>

## 2. 选择产品环境

选择产品安装目录，查看有界发现返回的候选、来源和模块，再明确选择本次环境。发现可能不完整；存在多个候选时核对实际产品、版本和入口。

E3D 2.1 使用 E3D2.1 Host；E3D 3.1 系列对应已交付的 E3D3.1.6 Host；AM、PDMS 使用各自 NET35 配置。可发现安装目录不表示已登录工程。

<a id="ownership"></a>

## 3. 核对来源与旧所有权

先读取旧安装记录和目标环境文件。已有旧环境所有权时，为本次移交单独生成预览，审阅后再明确应用。

遇到未知记录、文件漂移或所有者冲突，保留原记录和回执，先查清来源。不要删除标记来绕过冲突。

<a id="preview"></a>

## 4. 预览部署与 EVARS

核对工具包、所选环境文件、Host 配置和运行目录，选择引用现有文件或复制到独立运行根。预览应列出文件差异、环境修改、计划编号、摘要和恢复方式。

改变任何实际输入后重新预览。复制目标不能覆盖应用安装根；预览本身不表示部署已完成。

<a id="apply"></a>

## 5. 明确应用

只应用已经审阅的当前计划，并给予本次写入授权。后端会再次核对文件、摘要和所有权，按冻结范围写入并记录备份。

等待期间不要重复提交。查看回执中的成功、冲突、部分恢复或未知结果；结果不明确时转到[回执与恢复](recovery.md)。

<a id="recover"></a>

## 6. 核对回执与恢复

保留本次操作回执及恢复引用。恢复前检查目标和备份；只有仍属于本次操作的变化才可条件恢复。后续外部修改会形成冲突，需要先人工核对。

恢复可以保留未完成项和原因。部分恢复不能作为全部成功处理。

<a id="launch"></a>

## 7. 配置与启动

进入已有启动页，明确工程、模块和配置修订，审阅启动计划后再启动。凭据通过本次安全输入传入，不进入命令行、配置历史或公开回执。

入口进程已创建后，继续查看启动观察结果。进程创建、工程登录和 Host 核验分别确认。

<a id="verify"></a>

## 8. 严格会话核验

进入会话页，明确选择当前目标并核对 PID、完整启动身份、模块、管道和协议。按照[核验工程会话](connection.md)确认本次结果，再进行开发或读取。

Host 更新后完整重启对应 AVEVA，再重新发现和核验。旧灯态、历史报告和其他产品的验收结果不能替代本次核验。
