# 多 Ribbon 文档与全局单例工具

## Why

用户纠正先前功能库首屏方案：首先进入 Ribbon 编排，可打开多个 UIC；跨文件功能定位与 UIC/XML 关系查询按需求各提供一个工作区页面。不能把同一套功能库、检查和定位导航重复绑定到每个 UIC。用户同时要求柔化圆角与边框，并校核设计稿和实际视觉。

## What Changes

- 新 UIC 文档默认 Ribbon 编排，删除每文档三视图导航。
- 工作区单例“功能定位”收集 N 个 UIC，搜索名称、Macro、Tooltip，保留来源身份并精确跳回引用。
- 工作区单例“UIC ↔ XML”切换两种查询方向，按完整路径去重，明确扫描范围与未解析项。
- 部署保持单例，登记写入仍单独预览确认；点击 XML 数量进入全局关系查询。
- 功能定义通过所选对象详情编辑，普通使用不需要先进入功能库。
- 控件圆角 8、弹层 10、面板/表格 12，统一细淡边框并裁切子面板，保留焦点和禁用状态。

## Impact

本变更优先级高于 command-first-authoring 中的默认功能库与每文档三视图设计。保留共享定义/引用、增量撤销、多文件状态、后端写入校验。旧设计保留；新 FigCraft 源为 design/figcraft/workspace-tools-rounded-0.7.figcraft。DeepSeek Harness 的其他目录尚未由用户给出确切路径，不推断其改动归属。
