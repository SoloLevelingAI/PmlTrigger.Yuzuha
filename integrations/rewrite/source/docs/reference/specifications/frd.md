# FRD · 功能需求文档（压缩初稿）

## 任务流程

[适用范围](INDEX.md#范围与状态)。

| 任务 | 输入 → 处理 → 结果 |
| --- | --- |
| 配置 | 字段、CommitId → 校验提交 → 修订/回执 |
| 启动 | 配置、OperationId → 冻结、准入、启动观察 → 事实 |
| 监测 | 资源身份 → 探测归约、订阅 → 快照 |
| 部署 | 来源、目标 → 预览确认、互斥写入 → 回执 |
| 变量 | 新旧名、作用域 → 预览、基线比较、写后核验 |
| 分享 | 非秘密文件 → 预览、绑定确认、CommitId 提交 |
| 迁移 | 来源摘要 → 副本准备、核验、激活 |

## 异常与恢复

冲突或外部变化使旧计划失效；未知结果按原编号核验。恢复/回滚重新确认；停止等待不结束外部程序、不撤销写入。核对修订。
