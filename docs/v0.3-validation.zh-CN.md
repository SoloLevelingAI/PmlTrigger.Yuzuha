## 构建来源与验证边界

两个 MCP 均新编译为 0.3.0。预置 Host 及其依赖保持与已审查的 0.2.3 安装包一致。本机 AM/PDMS 的 PMLNet、Utilities 参考程序集文件版本均为 12.1.4.0；不分发这些 AVEVA 专有参考程序集。

尚未完成 AM/PDMS/E3D 实机兼容性验收，也未测量完整官方资料库的索引性能。脚本异常回滚测试不覆盖强制结束进程、断电或磁盘故障。发布说明保留这些边界，不将候选包表述为已完成 AVEVA 实机验证。

## 复现方法

使用仓库 NuGet.Config 还原依赖，将两个 .NET 10 项目发布到 runtime/net10，再运行上述两项测试。Native AOT 发布需要 C++ 原生工具链。针对解压后的候选包测试时，将 YUZUHA_TEST_PACKAGE 设置为包根目录绝对路径；测试数据写入包外目录。Profile 配置测试需要预置 Profile 文件布局。

构建完成后在新的输出目录状态下运行 `python scripts/Package-Release.py`，生成安装包、源码包和 SHA256 清单。安装包不包含本地数据库、经验、信任记录或 AVEVA 专有参考程序集。
