# 现有 UIC、托管边界与版本历史

## 原路径

本机 Marine 的 DesignCustomization.xml、OutfittingCustomization.xml 均登记：

~~~xml
<CustomizationFile Name="Ytools" Path="C:\AVEVA\PMLLIB\Other\UIC\YtoolsAM.uic" />
~~~

更新从后端持久化文档读取 sourcePath，继续更新 YtoolsAM.uic，不新增重复哈希 UIC。路径导入后可直接部署，无需接管或选定模块；确认后备份覆盖一次，记录所发现的关联。既有 Name/Path 和 XML 原字节保持不变。

可选接管保留已有草稿及源字节。该 UIC 被多个模块引用时，更新文件影响各引用；预览收集已发现安装和已知绑定中的关联，并明确报告无法读取的位置。

## 来源与权限筛选

表格按名称/路径、来源、权限和加载状态筛选，后端执行相同保护。

| 分类 | 判据 | 操作 |
| --- | --- | --- |
| 部署器托管 | 后端明确绑定；旧版须验证备份凭证与当前文件摘要 | 编辑、部署、移除/恢复加载 |
| 既有自定义 | 可读取的安装外绝对路径 UIC，尚无托管记录 | 可直接编辑并备份覆盖；加载管理需已托管 |
| 原生/系统保护 | 安装内其他既有条目、项目占位路径 | 只读 |
| 未识别只读 | 来源不能核验，包括只有部署器名称前缀而无凭证的文件 | 只读 |

原生/系统保护是保守策略，并非厂商签名鉴定。不能认为所有非托管文件都来自 AVEVA 官方，也不凭名称自动授予权限。

“移除加载”仅撤销选中的 CustomizationFile 登记，保留 UIC 和历史。已移除的托管项仍显示，可恢复登记。恢复时重新加入当前清单，当前模块的其他条目保留；精确完整清单恢复可使用快照/备份并核对后续修改。

## 持久数据

data/uic-workspace/documents/<标识>/ 包含文档索引和版本 JSON。每个文档自动编辑草稿只留最近 5 次，后续保存时删除更早草稿文件。手动保存、原始导入字节、接管基线、部署前后文件、失败、加载状态修改及恢复快照长期保留。版本序号持续递增，列表数量为实际保留数。相同内容的手动保存也能建立长期快照；仅打开部署预览不会建立长期快照。

自动记录有约 0.9 秒防抖，确认底部“已记录版本”后再关闭。外部编辑器改动不会后台自动监视，重新导入会产生新源快照。磁盘故障或崩溃可能中断尚未完成的记录。

正式目录已从 Git 排除，更新应用时不能清理。迁移请备份整个目录，或使用 UIC_DATA_DIR 指定并保留其他目录。自动轮换只清理超过 5 次的纯编辑草稿，长期快照和实际文件备份保留。

## 查看与恢复

已有本机 UIC 点击部署进入“更新 UIC 文件”，自动收集关联模块，可按模块、安装及名称筛选。确认后备份并覆盖 UIC 一次，原有模块 XML 保持原字节。无需选定某个 XML 才能更新，共用此路径的模块重新加载 Ribbon 后读取同一更新文件。

顶部“加入模块”直接打开独立页签，选安装、收集模块、选择需要的模块并预览确认，只增加对应 XML 的加载关联，不覆盖 UIC。部署窗口也可在“更新 UIC / 加入模块”之间切换。管理表仍用于移除/恢复具体模块中的托管关联。关联收集范围是已发现安装及已知安装提示；读取失败会显示。

加入页签使用穿梭框：左侧是未关联模块，右侧是“已关联”和本次“待加入”。两侧支持搜索与全选；勾选后点箭头移动。已有加载固定在右侧，左移仅取消本次待加入项。批量预览列出全部新增项，确认后逐个备份并写入；部分失败显示已成功数量，剩余选择保留。移动列表和预览不会写实际 XML。

“管理 / 历史 → 持久化文档与版本”支持文档筛选、打开版本、导出 UIC、下载原始 UIC 及恢复。

查看旧版本载入编辑器供检查；恢复会追加新记录，保留后续版本。两者不会自动覆盖实际 UIC，应用到 AVEVA 需要检查后再次部署。

下载原始 UIC 使用导入或接管基线中的原始字节，可供精确字节恢复。一般版本导出依照 32/16 图标规则重新生成。完整清单恢复仍可使用留存快照及备份，应先核对是否有后续需保留的修改。

## 支持范围

当前可编辑普通 Tab、Group、Macro ButtonTool。可见非 Macro 工具、上下文 Tab、危险 DTD 或不能安全保留的结构会明确拒绝，不静默删掉。

快捷键、帮助字段、额外属性、未编辑富文本提示及其他 XML 容器保留。如果删除按钮会破坏保留容器中的引用，导出会阻止该结果。

真实 AVEVA 加载与 Macro 执行仍待实机验收；不会运行导入文件中的命令。
