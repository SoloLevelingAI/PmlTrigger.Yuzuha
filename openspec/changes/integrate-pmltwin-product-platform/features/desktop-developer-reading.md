# 开发者桌面阅读动线优先 · 2026-11-01

## 总体契约

用户明确主要使用者为电脑端开发者。桌面动线 SHALL 成为本轮主要设计及验收对象：项目航图选任务 → 常驻路径定位步骤 → 同页切换契约/实现/验证 → 返回或继续步骤。MUST NOT 为复用手机布局而压缩桌面信息组织，也不能先让用户滚过长说明才看见路径或详情入口。

手机端以后可单独设计；仅共用语义配色、契约数据及身份，不要求共用DOM、列数、排版或导航。当前小屏保留基本访问，不以手机精修或手机布局一致性作为桌面方案通过条件。本契约优先于本次候选方案此前要求桌面/手机复用布局的解释；既有历史手机验证事实保留，不升级为新布局验收。

## Feature细约

ION项目航图保留酸性编辑式主视觉。进入Feature/Script后，桌面采用任务工作区：所属项目/Feature与原flow/step路径持续可见，当前内容区提供摘要、完整契约、实现方法、验证证据的明确切换。主要路径和详情切换在1920×1080、1440×900首屏可见，1024×768检查紧凑桌面可达；长字段和源码在对应内容区滚动，不推走步骤导航。

用户追加并明确面包屑为「主页 → Feature(A) → Script(A) → Script Method」。工作区顶部 SHALL 按此契约/实现层级显示，父级可直接进入，不要求反复返回。步骤路径仍在侧边流程区，不混作面包屑末级。未选择方法时终止于已选Feature/Script，方法就绪后末级为方法名；尚未登记Script归属的Feature级方法明确显示缺少关联，不能按同名类猜所有者。静态关系到达的其他方法标明关联阅读，不冒称Script直接绑定或执行轨迹。

当前项用文字及aria-current说明；长名可在导航内合理缩略但完整名称可访问。方法内部保留回绑定入口的关系导航。面包屑、侧边步骤及内容tab共享同一entity/flow/step/method选择，主题切换不丢位置。

方法区首屏 SHALL 优先展示可选择的方法、签名及源码入口。重复标题、完整分析清单与修订身份进入摘要或折叠区；常显一条简短静态分析边界，完整范围按需展开。方法名可省略命名空间以便扫描，但完整签名、重载身份和来源须保留并可访问。修订摘要必须取自真实共同修订，不能显示空身份或虚构值。

直接选择步骤与调用关系保留原独立ID；无登记流程不编造步骤。进入方法时路径留在侧边，不能以跳转旧Atlas或全屏遮盖路径作为桌面默认方案。方法仍允许其他独立候选或小窗通过同页对话框访问。

规范、实现、验证分别说明。Script引用所属Feature的证据须明确关联范围，不能把Ribbon外观实机通过写成pending脚本独立通过。未登记证据明确显示未关联，既有局部报告未登记的问题不靠颜色或整体通过推断补齐。页面只读，当前步骤为阅读位置，不执行工程动作。

主题切换仅改变语义变量；步骤、当前详情分支、方法、展开、滚动和焦点保持。返回项目航图、切任务/步骤及关闭方法区都有可见入口；销毁旧任务时取消旧方法请求，迟到回执不写入新任务区。

## 内部Script细约

### 面包屑同级切换补充契约

用户要求在当前位置直接选择同级对象，无须先返回父层。桌面面包屑 SHALL 保留「主页 → Feature → Script → Script Method」，每级名称仍用于返回该层，旁边独立下拉按钮用于同级切换；当前级也可以打开候选。主页没有同级菜单。布局延续ION的编辑式排版、细分隔和同源六主题；菜单使用稳定正文底面、清楚的当前标记和短标题/完整提示，不叠加大块无关说明，不改变任务工作区的左右动线。

候选 SHALL 从当前已验证元数据和内部目录提取，按原登记顺序展示，选择身份始终使用ID：

| 级别 | 同级集合 | 当前层缺失或无法读取 |
|---|---|---|
| Feature | 当前项目的全部Feature，不按当前分组缩小 | 没有Feature则说明未登记 |
| Script | 当前Feature的显式scriptIds，只取有效引用；不是全项目Script | Feature有Script但尚未选择时提供「选择Script」；无关联时显示空态，不猜归属 |
| Script Method | 当前明确Script的精确绑定根methodIds，只在活动方法目录ready、同metadata/render双摘要且Script身份匹配时可用 | loading/stale/关闭/未绑定/Script归属不唯一时不提供旧候选，说明原因；相关调用方法不扩大同级集合 |

方法菜单不能列出全393项目录或将直接下游当作同级。重载需以完整签名提示区分；短显示名不代替完整符号身份。选中静态关联方法时仍标明关联阅读，菜单仅提供返回该Script绑定根的选择。

切Feature一次直接进入新Feature，清除旧Script、旧step、旧region和旧方法正文；切Script一次直接进入当前Feature下的新Script，并显式保留该Feature所有者。两者保持配色、顶层pathname和当前摘要/契约/方法/证据栏目；新任务正文及滚动重新开始。flow由已有规范化规则重新选择，仅唯一流程可预选，step不从上一分支继承。不得先选父层再选子层形成多条历史。重选当前ID仅关闭菜单，不重建正文、不请求方法、不增加历史。

选同级方法 SHALL 在当前方法面板就地选择，保留entity/Feature/flow/step/主题，复用当前有效目录，不重新请求后端；旧方法正文先替换为新选择的真实签名/源。此次方法选择沿用面板内导航，不新增URL方法参数或浏览器历史；刷新/历史回到实体后重新校验有效绑定，不能承诺精确方法书签。Feature/Script的既有hash和reader参数继续支持前进/后退及刷新。

菜单为非模态选择面板，展示当前项、可选总数、名称及ID/完整签名；支持按名称/ID搜索，搜索无结果与未登记分别说明。点击只展开，不触发导航；鼠标或Enter/Space提交候选。ArrowUp/Down、Home/End可在可见候选间移动，Tab可自然进入/退出；Esc或点击外部空白关闭并回到仍有效的触发按钮，点击其他可操作控件则保持该控件原生焦点及操作。提交新实体后焦点到新标题；提交方法后焦点到新方法标题。只允许一个菜单打开；滚动、窗口变化、切步骤/栏目/实体、共同修订或方法有效性变化时关闭旧菜单，迟到候选不能写入新上下文。

同Script切流程步骤继续保留方法、展开与滚动；随后关闭方法仍须返回当前工作区摘要。关闭回调以当前有效mount所有者、实体、双摘要及连接容器判断，不能依赖最初打开时的导航代次误拒绝，也不能让旧句柄改变新工作区。候选和源码仍为内部只读能力，不引入工程操作或公开源码投影。

### 同级切换内部接口

方法组件提供`getSiblingMethods(identity)`与`selectSiblingMethod(methodId, identity)`，identity含活动Script与metadata/render双摘要，并可携带读取时的ownerId/revisionId；输出包含available、reason、revisionId、ownerId、活动实体/Script、当前methodId和有界choices。选择额外返回selected/changed，重选当前方法为selected=true/changed=false。读取和提交均复验活动owner、ready、Script归属、原绑定与双摘要；无效返回空候选/拒绝，不抛出旧源码为当前内容。WorkBench携带同次快照的ownerId/revisionId提交，从受限接口读菜单，通过方法选择事件更新末级名称；不自行读取或缓存整个内部目录。Feature/Script候选直接消费公共同源模型。

### 同级切换验收

真实浏览器核对完整Feature、所属Script和精确根方法集合，直接切换正文/方法源及SHA、零新标签/零顶层跳页、栏目/主题保持、旧分支清除、重选不重建、搜索/空态/单项/键盘/外点/焦点，以及Feature/Script历史/刷新。以1440/1920主验收、1024菜单触达与无溢出复核；六主题抽查菜单实色和对比度。迟到、旧摘要、跨Script方法与关闭清候选由隔离fixture补充，不能当真实Roslyn源证据。实际截图代理目检，用户视觉确认及FigCraft深化状态不升级；原27项业务任务保持。

| 单元 | 输入/前置 | 方法/副作用 | 校验/回执 | 恢复 |
|---|---|---|---|---|
| ION桌面工作区 | 同源entity/flow/step/三轴数据 | 路径常驻、内容区切换与内部滚动；只读 | 首屏路径/分支入口、原七字段/证据范围 | 无流程说明、失效目标回有效任务 |
| 方法dock | 当前任务及有界目录 | 在工作区挂载，与dialog共用读取逻辑 | 同摘要/精确绑定/当前源 | 旧句柄不影响新实例，过期清正文 |
| 主题控制 | ION主题白名单 | CSS变量更新，不重建工作区 | 路径/方法/展开/滚动保持 | 无效偏好回默认，本次可用 |

## 验收与汇总

桌面先验收1920/1440，紧凑桌面1024复核；选择任务、步骤、契约、方法、验证及继续/返回无需在长正文中找入口。验证「主页/Feature/Script/Script Method」面包屑、直接回上层、当前项及历史一致、键盘可达，流程步骤继续单独显示。方法不打开新标签，长正文/源码滚动时路径位置不动；切六主题保持当前阅读状态。手机独立布局标为后续设计，FigCraft深化仍由用户指定区域。原27项业务任务不变。
