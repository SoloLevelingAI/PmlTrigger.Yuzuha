## 原型

- 01 `收起` → 03；03 `展开 Ribbon` → 01（1280×800 往返）
- 02 `收起` → 04；04 `展开 Ribbon` → 02（1100×740 往返）
- 01 左栏收起 → 05；05 左右竖轨展开 → 01
- 01 / 03 / 04 停靠区 `↗` → 06；01「放大停靠区」→ 09；09 `↗` → 06
- 06 / 07 / 08「停靠回主窗」→ 09；关闭 → 01
- 流起点：01（18212）、02（19703）、06（19006）、09（19368）

限制：静态状态稿，不支持连续拖拽调宽；页签切换、列宽拖拽与 Tooltip 动效为示意；数据为设计样例。

## 待确认后（WPF）实施要点

- 承载：Ribbon 高度改为可折叠附加属性，默认展开；左右栏用 6 px GridSplitter 替换固定列宽，折叠切换 48 px 竖轨模板。
- UIC 预览：按 UIC 定义生成，列内最多 3 行，组标题底部对齐；不得写入设计稿中不存在的按钮。
- 表格：统一行模板，名称块与单行字段都按行高居中；图标列只放图标。
- 浮动窗：同一视图模型承载到独立 Window，标题栏合并为单条；停靠时移交同一视觉树。
- 布局 schema 增量：`LeftPaneWidth`、`RightPaneWidth`、`LeftPaneCollapsed`、`RightPaneCollapsed`、`RibbonCollapsed`；缺省值 = 232 / 300 / false / false / **展开**。
- 业务与传输层不变：查找、批量修改、部署、登记仍走现有控制器与增量撤销；写入确认保持两步。

## 最终部署语义复核

部署窗的写入对象是已选 UIC 文件。已关联 XML 只读展示：样例 YtoolsAM 有9个引用，列表显示其中5个，不代表向5个XML写按钮。确认后先备份再更新 UIC，已有关联沿用更新；新增/修改模块登记使用独立的登记预览。首次部署生成 UIC 文件，不能标成自动新建登记。样例原文件位置为 C:/AVEVA/PMLLIB/Other/UIC/YtoolsAM.uic。
