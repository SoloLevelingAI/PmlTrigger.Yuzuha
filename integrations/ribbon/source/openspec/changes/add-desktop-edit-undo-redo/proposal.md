# 增加桌面编辑撤销与重做

## Why
用户希望通过 Ctrl+Z/Ctrl+Y 回退误操作，拖拽排序、跨 Group 移动和剪切粘贴无需进入持久历史恢复。

## What Changes
- 为当前文档增加有容量上限的会话编辑栈，覆盖结构、属性及剪贴板引起的编辑。
- 提供工具栏撤销/重做和快捷键，右键入口放进已有子菜单，保留原顶层数量。
- 输入框与组合框保留文本原生快捷键；撤销或重做后更新树、当前 Tab、属性与自动草稿。
- 自动保存和手动快照不产生额外撤销步骤；打开其他文档清空会话栈，部署文件不随撤销反写。
- 增加原生回归并更新说明。

## Impact
仅 WPF 客户端及验证、文档变更。独立后端、部署确认、持久快照保留规则不变。
