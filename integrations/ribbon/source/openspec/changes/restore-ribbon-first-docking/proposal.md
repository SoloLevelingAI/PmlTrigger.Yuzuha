# 恢复 0.5 视觉方向与 Ribbon 主视角

## Why
用户认为 0.7–0.9 的主视角偏离 Ribbon，需要先在 FigCraft 回到 0.5 的 Office 式 Ribbon、结构树、中央预览和右侧属性，减少独立页面，用停靠页承载辅助任务。

## What Changes
- 先完成并确认 FigCraft 修订，再集成到 WPF 0.10，保持现有后端与业务语义。
- 顶部恢复完整大/小命令组合的 Ribbon，浏览标签仅放 UIC 文件。
- 中央 Ribbon 预览保持显示，左结构树含实际图标和未放置按钮，右侧恢复完整参数编辑区。
- 下方共用三个停靠页：按钮 / 查找、UIC ↔ XML、部署；查找以范围选择合并进对照页。
- 保留浮动、底部停靠预览、布局恢复和增量撤销，扩展布局保存为底部高度、收起状态和查询范围。

## Impact
保留可编辑设计源、旧设计与四种同窗口状态预览。WPF 视图承载调整为固定 Ribbon 与底部工具槽；后端 HTTP 服务和业务模型不变。新增原生布局及独立进程重启回归。
