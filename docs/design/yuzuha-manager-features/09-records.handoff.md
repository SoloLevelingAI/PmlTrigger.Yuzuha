## 行为与边界

把下一步操作放在错误旁边。错误文字保留可读原因和定位信息。已发出的动作结果未知时，先回收证据，避免自动重复。

后端归属：旧通信诊断 + 管理回执；统一记录页查询待接线。

- `runtime.calls`
- `runtime.status`

## 必须验收

1. 暂无记录：说明何时生成记录。
2. 处理中：显示当前阶段与关联号。
3. 筛选无结果：保留筛选并提供重置。
4. 错误定位：展开日志、目标与异常类型。
5. 恢复待处理：定位每个未完成项。
6. 结果未知：先回收回执，不自动重发。

主操作 → 状态审阅页 → 返回主画面有原型链接；它不是后端操作模拟器。参数编辑、真实表单校验、屏幕阅读器与键盘行为需在 WPF 落地后测试，不能从静态稿推定通过。
