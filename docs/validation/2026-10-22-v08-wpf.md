# PMLTWIN v08 WPF 界面更新

代码基线为 PR #7 的 `4ba3f17c5fe1f080ad6cc5bd054362456181ccfa`，设计输入为 PR #8 的 `f14df2beb4cdc6f797d50f16b45ad03931680bbb`。本批改动位于本地分支 `codex/pmltwin-v08-desktop`，验证对应未提交工作区。设计源文件原样保存在 `docs/design/pmltwin-v08/`，没有修改原稿。

用户选择的范围是“更新现有页面，并完善已有后端支持的配置操作”。未把原型中的评审、测试执行、Web 应用登记和知识条目发布当成已经实现的后端能力。

## 界面与配置

- 从实际 FigCraft 文件读取 26 个颜色变量；原始导出、来源提交和文件哈希保存在 `design/figcraft/v08-theme-tokens.json`。Light/Dark 字典使用这些色值，同时保留现有资源名称以复用业务绑定。
- 更新中性侧栏、普通会话卡片、单一蓝色强调、同色相图表、正文与辅助文字。标题 28 DIP，正文/表格 13 DIP，辅助文字 12 DIP，最小字号 11 DIP。修复深色表格中的固定浅色分隔线。
- 14 个主页面覆盖总览、启动工程、配置库、插件部署、工程会话、能力与函数、原生查询、AI 运行、工具日志、知识库、设置及原有三个待接入页面。小窗口保留独立滚动导航，将环境与账户信息收起以留出操作空间。
- 配置库提供名称/项目/路径搜索、实际产品筛选、收藏、最近启动、编辑、独立复制、设为默认和删除。配置直接复用 `WorkspaceSettings`，保留现有启动参数与 Windows 凭据机制。
- 新建配置在保存前保持为草稿；副本使用独立 ID、环境字典和空凭据引用。删除必须输入完整名称，只移除所选配置与不再被其他配置引用的本机凭据；删除默认项时选择一套剩余配置。最近启动记录只表示启动入口进程已创建。

## 复现与预览

在仓库根目录运行：

```powershell
dotnet build YuzuhaToolkit.Development.slnx -c Release
dotnet test YuzuhaToolkit.Development.slnx -c Release --no-build
./scripts/Test-Desktop.ps1 -OutputDirectory artifacts/tests/v08-desktop
./scripts/Build-Desktop.ps1 -OutputRoot artifacts/v08-preview
./scripts/Test-Desktop.ps1 -NoBuild -ExecutablePath artifacts/v08-preview/YuzuhaToolkit.Desktop.exe -OutputDirectory artifacts/tests/v08-published
```

本次本地可运行包位于工作区的 `outputs/PMLTWIN-v08-WPF-20261022/`。入口为 `YuzuhaToolkit.Desktop.exe`；“启动工程 → 配置库”进入配置管理，侧栏底部切换明暗主题。发布包中的 `build-info.json` 记录二进制哈希和验证范围。
