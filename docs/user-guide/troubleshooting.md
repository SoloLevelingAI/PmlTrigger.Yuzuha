# 排查常见问题

| 问题 | 先检查 |
| --- | --- |
| 已安装应用，但工程没有接入 | 进入[环境准备](install-to-operation.zh-CN.md#environment)，核对所选产品、环境和部署回执 |
| 没有发现会话 | 核对正确模块是否已打开，以及对应环境中的 Host 是否加载 |
| 更新 Host 后仍显示旧版本 | 完整重启对应 AVEVA，再重新发现和[核验身份](connection.md) |
| 计划失效或摘要冲突 | 回读现状并重新预览，不复用旧授权或手改摘要 |
| 按钮等待很久 | 保留原调用和回执，按[未知结果](recovery.md)核对，避免重复提交 |
| 知识结果不适用 | 检查来源、产品和版本，回到完整内置指南 |
| AI 客户端仍调用旧入口 | 重新加载当前 Skill，核对已安装 CLI 路径和实际 `op list` |
| 开发 API 页面打不开 | 打开[开发参考说明](developer-reference.md)，选择同版本的已解压目录 |

排查时记录实际安装路径、产品与模块、操作 ID 和脱敏回执。界面可见、进程存在、连接核验和业务完成各有独立结果，应按本次任务逐步确认。
