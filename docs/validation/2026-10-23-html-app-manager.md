## 环境与部署

Windows，.NET 10.0.11 / SDK 10.0.400-preview.0.26322.102，PowerShell 7.6.5；真实 E3D 2.1 / NET48 Host 0.3.2.0，Host 模块报告 Unknown。发现并核验明确 PID、启动时间和专用管道；不回退共享管道。

使用已有开发部署脚本核对会话 PMLLIB，将自有 `YuzuhaHtmlData` 与验证宏复制到独立 `YuzuhaHtmlManager` 子目录，然后 REHASH ALL、Object reload、新建实例验证。修正过程各轮有独立回执与覆盖备份。没有 PMLCMD、E3D 命令注册或新增 Host 协议，也没有保存模型。

本地 HTTP 宿主仅作为 HTML 与现有 .NET/IPC 的接入层；网页不直接连接命名管道。最终独立发布包实际启动后，再执行完整验证；不是仅测试源码或生成的静态页面。

## 发现与修正

首次调用在新增适配器第 45 行遇到 `(47,15) CP: Syntax error`，原因是 E3D 2.1 不接受将该比较表达式直接接 `.string()`；改用布尔局部变量，再转换字符串。失败后停止，原请求没有自动重发，原失败证据保留。

单项计数最初依赖格式化路径匹配，忽略 VAR VAR 类型文本前的空格，出现值正确而 Meta.Returned=0。最终改从 Walker 缓存节点判断指定路径及错误状态；首、中、尾与完整结果再次逐项比较通过。Web 新旧字段大小写及旧错误提示也已修正。
