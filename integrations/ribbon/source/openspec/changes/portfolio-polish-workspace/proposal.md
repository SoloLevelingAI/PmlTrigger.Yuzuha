# Ribbon Studio 0.12：按 Feature 并行评审与视觉统一

## Why

0.11 的默认主窗、折叠态和浮动工具已齐备，但命令节奏、文件关闭状态、编辑作用域和部署预览的表达仍不一致。用户要求以作品集的完成度优化 FigCraft，并按 Feature 让多个子代理并行审查后统一合并。

## What Changes

- 通过 CCSwitch 配置的真实 Claude Code CLI，并发运行编辑器、按钮编辑、登记部署三个只读评审；一个写入者串行修改原生文档。
- 新建 0.12 原生设计页、控件状态页和作品集页，保留 0.11 所有原有节点与原图资源。
- 保留顶部完整编辑器 Ribbon、文件 Tab、中央 UIC 预览及底部三个辅助停靠页；优化字体、图标、细线与留白。
- 明确当前单项设置与勾选项批量修改；补齐批量应用/撤销/重做、跨文件只读定位、空态及部署成功/失败的示例状态。
- 补齐文件关闭/脏标记、统一版本、原生只读保护、目标逐项预览和备份位置。
- 增加原生变量、文本样式、组件变体与实例；制作保留 1:1 产品视口的可编辑作品集展示板。

## Impact

- 本轮仅交付 FigCraft 设计与静态交互原型。未修改 WPF、后端、HTTP 契约或真实 UIC/XML。
- 延续 `adaptive-ribbon-and-floating-tools` 的侧栏宽度、浮动停靠与重启恢复要求；此轮的设计样例不构成这些运行时功能的实现证明。
- 源：`design/figcraft/ribbon-studio-portfolio-0.12.figcraft`；交付目录：`design/figcraft/portfolio-0.12/`。
