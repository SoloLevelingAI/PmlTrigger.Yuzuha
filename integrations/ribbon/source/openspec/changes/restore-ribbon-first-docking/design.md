# 单一 Ribbon 主视角

设计源：design/figcraft/ribbon-first-docked.figcraft。基于 0.5 的原生设计修订，保留旧页面，新建“Ribbon 主视角 · 0.5 视觉恢复 · 底部停靠”设计页。新图标取自持久化 Ytools 文档中的图片资产，不使用数字或通用网格占位；资产作为图片嵌入原生源，文本、框架、矢量与原型仍可编辑。

布局顺序仍为标题栏 → Office 式 Ribbon → UIC 文件标签 → 内容。中央以当前 UIC 的 Ribbon 预览为主，左侧结构树与未放置按钮，右侧显示当前按钮的图标、Group、Macro、Tooltip。Group 和显示大小属于当前引用，定义属性在当前 UIC 的引用间共享，不能因恢复旧外观而退回错误的数据语义。

辅助区域只有一组下方停靠页：

| 停靠页 | 职责 |
| --- | --- |
| 按钮 / 查找 | 默认当前 UIC 的可批量编辑对照；范围改为已打开 UIC 时只读查找、定位，不批量改写其他文件 |
| UIC ↔ XML | 当前文件的登记计数、版本和 XML 详情；显式进入管理登记，不自动写入 |
| 部署 | 批量加入、配置复用和状态核对；预览后再明确确认写入 |

切换停靠页不替换中央预览，也不增加顶层工具标签。历史、配置及布局等低频入口放在更多菜单，避免永久占一页。“放大停靠区”只调节停靠区高度，至少保留约 180px 的 Ribbon 可见区域；大面积对照可按需拖出停靠页，主视图仍保留。

后续继续保留 0.9 的辅助窗位置/大小/停靠状态恢复。停靠目标调整为下方工具区，预览只高亮该停靠区域与目标标签，不覆盖整个 Ribbon 主视角。复杂或易误触的最终写入确认仍可单独显示，不以分割线强行合并所有职责。

四个画板是同一窗口的状态（默认对照、跨 UIC 查找、XML 登记、部署），不是四个新增产品页面。停靠页与范围菜单可通过原型切换，其余操作是布局示意。示例数量与路径不代表本轮执行了实时扫描；没有修改真实 UIC/XML。

设计检查：四个 1280×840 状态分别渲染复核，可见直属元素无画板越界。用户确认后已在 WPF 0.10 集成；后端与 HTTP 契约不变。

## WPF 集成

BottomDock.cs 承载固定三个工具槽，文档浏览标签只保留 UIC。工具控制器与当前文档会话分开，登记管理和历史复用 XML 槽中的临时内容，不制造第四个固定页签。比较表和只读跨文件查找共用第一槽，原有批量修改仍使用差量操作历史。右侧恢复完整属性，标识修改同步本功能的引用。

中央网格约束预览最小高度 180px；底部高度根据可用空间约束，扩展详细表格只改变底部承载。浮动时移交同一个工具视觉树，停靠预览 Adorner 的目标由顶层浏览标签改为底部 TabControl。

现有布局 schema 1 增加可选 DockHeight、DockCollapsed、ComparisonScope 字段；旧配置缺省回退正常高度与当前 UIC 范围。ActiveTool 跟踪底部当前工具，保存继续使用本地前端原子替换；不恢复待确认写入计划。
