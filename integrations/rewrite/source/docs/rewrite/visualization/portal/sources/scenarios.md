# Archon 候选：验收与故障场景

这些是未来实现必须满足的场景，本轮只检查覆盖与设计一致性，不宣称已运行真实应用测试。

### AR01 没有开发服务的普通使用

需求：R01。

- **WHEN** 本机断网且没有 Archon、Aspire 或 Node.js。
- **THEN** 独立 WPF EXE 打开本机目录并允许本机任务，诊断故障不阻断业务。

### AR02 自定义程序与人工入口

需求：R02。

- **WHEN** 用户添加 PML AI / 通用 EXE 并覆盖发现的入口。
- **THEN** 保存明确版本和人工路径；下一次扫描只追加候选，不改绑定。

### AR03 空白新增和独立复制

需求：R03。

- **WHEN** 用户分别执行新增与复制，并按版本搜索。
- **THEN** 新增无继承字段；复制有独立 ID；搜索不改变持久配置和凭据。

### AR04 密码的输入生命周期

需求：R04。

- **WHEN** 用户临时显示密码、保存并重新进入页面。
- **THEN** 明文不回填；运行时从本机凭据引用解析，日志与任务投影没有密码。

### AR05 并行版本的环境隔离

需求：R05。

- **WHEN** 两个版本同时启动且选了不同许可。
- **THEN** 两个子进程分别得到许可变量，Windows 全局环境及父进程不被改写。

### AR06 瞬时超时

需求：R06。

- **WHEN** 某次许可探测超时但本轮重试成功。
- **THEN** 状态短暂复查后恢复，计数清零，不发虚拟机丢失通知。

### AR07 虚拟机存活但服务故障

需求：R06。

- **WHEN** 虚拟机进程存活，端口连续三轮失败。
- **THEN** 分别展示进程存活和端口不可达，只发一次断连通知；不混淆两个事实。

### AR08 过期就绪证据

需求：R06。

- **WHEN** 启动前只剩超期 Ready 快照。
- **THEN** 重新探测，不用过期绿色授权本次启动；端口成功仍不证明签出。

### AR09 进程入口交接

需求：R07。

- **WHEN** mon.exe 退出后目标模块子进程继续运行。
- **THEN** 操作仍在观察；窗口出现仅记 WindowObserved，项目就绪需要单独会话证据。

### AR10 窗口迟迟不出现

需求：R07。

- **WHEN** 90 秒没有窗口但进程尚可能存活。
- **THEN** 任务保留 Unconfirmed，继续有界核对，不自动重放登录。

### AR11 跨页面查看和关闭跟踪

需求：R07、R13。

- **WHEN** 任务进行时离开页面，之后停止观察或退出工作台。
- **THEN** 投影和结果仍可查；停止观察释放句柄，不终止目标应用。

### AR12 刷新最新与选择旧版

需求：R08。

- **WHEN** 用户先选择旧 ZIP，再重新打开预览，最后点击刷新最新。
- **THEN** 打开预览保留旧选择；显式刷新才扫描最新完整 ZIP / 7z。

### AR13 目录与文件映射

需求：R08。

- **WHEN** 用户选择完整文件夹或普通文件并设置相对目标。
- **THEN** 直接形成只读预览，不要求压缩，不执行内容。

### AR14 计划在确认后过期

需求：R09。

- **WHEN** 来源摘要、工作空间修订或真实目标在确认后改变。
- **THEN** 拒绝执行旧计划，返回差异并要求重新预览。

### AR15 同目标竞争

需求：R09。

- **WHEN** 两个已确认任务解析到同一真实目录。
- **THEN** 只有一个写入，另一个等待或冲突；路径别名不能绕过互斥。

### AR16 写入中断与重启

需求：R09。

- **WHEN** Worker 在部分写入后失联。
- **THEN** 回执保留；任务为待恢复或不确定，重启只核对，不自动重新安装。

### AR17 回滚遇到外部修改

需求：R09。

- **WHEN** 最新成功部署有备份，但目标在之后被改动。
- **THEN** 回滚报告冲突，不能覆盖后来修改或假报成功。

### AR18 只保存与持久应用

需求：R10。

- **WHEN** 用户保存变量配置但没选应用，之后改名遇到冲突。
- **THEN** 仅保存不写 Windows；持久改名检查原值和新名，拒绝覆盖冲突和保留变量。

### AR19 外机分享与无副作用导入

需求：R11。

- **WHEN** 用户导出包含工具关系的包后在外机导入。
- **THEN** 排除秘密、凭据引用、回执、备份和本机应用状态；只产生待绑定草稿。

### AR20 数据位置不可用

需求：R12。

- **WHEN** portable 目录不存在或不可写。
- **THEN** 可创建缺失目录，不可写时明确报错，不切换到其他空配置或伪造数据。

### AR21 从不同当前目录启动

需求：R12。

- **WHEN** 相对 DataDirectory 已配置，快捷方式工作目录不同。
- **THEN** 始终从 EXE 所在目录解析，不重复生成工作空间。

### AR22 旧配置转换失败

需求：R12。

- **WHEN** 含关联、凭据引用和历史根的旧数据转换中断。
- **THEN** 原文件不变，转换临时结果不能替换有效文件；ID 和关联可核对。

### AR23 视觉与窗口缩放

需求：R13。

- **WHEN** 在三种逻辑工作区和不同 DPI 操作所有页面。
- **THEN** 按 FigCraft 核对图标、颜色、圆角、下拉和密码显隐；主要操作固定可见。

### AR24 停止开发编排

需求：R14。

- **WHEN** 开发 DevHost 退出而真实 VM、AVEVA 与许可仍运行。
- **THEN** 外部资源不被终止，普通工作台用例仍独立可用。

### AR25 未来执行端离线

需求：R14。

- **WHEN** 设备能力不匹配或网络不可达。
- **THEN** 只禁用相应远端任务，本机可用；秘密留在执行端，检查交互会话。

### AR26 取消管理员提示

需求：R09。

- **WHEN** 受保护计划已经确认但 UAC 被用户拒绝。
- **THEN** 未发生写入，记录取消/权限原因，普通主窗口保持可用。

### AR27 导入后缺少本机路径

需求：R03、R11。

- **WHEN** 分享包包含其他电脑的 mon.exe 与初始化文件路径。
- **THEN** 导入进入待绑定状态并指出缺失项，不默认使用错误版本。
