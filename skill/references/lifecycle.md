# Installation and updates

Use the formal Phayton Windows setup and the package INSTALL.md. The development/source supplement is not an installer. The obsolete PowerShell MCP installer, updater, uninstaller and registration chain have been removed.

Discover the current installation, generate a concrete preview, check its targets and hashes, then apply only the approved scope. Preserve the user knowledge directory and backups. Legacy installations require an explicit migration plan, not an overlay.

The installed entry is runtime/cli/PmlTwin.Phayton.Cli.exe. AVEVA integration, MCP removal and Skill updates belong to the setup preview. Independent MCP servers stay disabled. Use op list / op describe to discover the current native contract; never restore stdio registration as a repair step.
