# Spec Delta

## Purpose

允许管理器按需附加许可诊断和虚拟机实验能力，让普通用户只安装基础功能，同时使需要测试环境的用户从同一 GUI/CLI 发现并运行插件任务。插件的可用性、操作范围、运行证据和停用状态必须清晰，避免后台启动未选择的外部操作。

状态：候选，未 sync/archive。显式包清单、安装启停、独立 worker 契约、许可诊断与 VM 计划/模拟/授权任务已实施，并有合成夹具和实际工作包的临时登记验证。新插件 Feature GUI 仍待接线；本轮未做真实许可签出或 VM/VIX 执行，原型与模拟记录不能代替实机验收。当前定位见 [design.md](../../design.md#现有源码与测试定位)，范围与限制见 [实施验证](../../implementation-verification.md)。

## ADDED Requirements

### Requirement: 插件按显式登记提供 GUI 和 CLI 能力

管理器 SHALL 列出插件版本、契约兼容性、启用状态和可执行操作。只有存在兼容且已启用的登记时才提供对应动作；未安装、禁用或加载失败的插件 MUST NOT 阻断基础部署、启动、知识管理与 AVEVA 通信。

#### Scenario: 基础安装未安装插件
- **WHEN** 用户安装基础管理器而没有许可或虚拟机插件
- **THEN** 可以正常部署、启动和测试 AVEVA 连接，插件入口显示未安装

#### Scenario: CLI 调用禁用插件
- **WHEN** 管理器 CLI 请求禁用或契约不兼容插件的操作
- **THEN** 返回明确不可用原因，且不启动插件工作进程

### Requirement: 许可诊断保留证据层级

许可插件 SHALL 分别报告端口可达、本地服务状态和具有实际证据的许可签出结果。没有签出证据时 MUST 标为未验证；未启用预检时基础启动不依赖诊断结果，显式配置强制预检时才据该策略处理启动。

#### Scenario: 许可端口可达
- **WHEN** 检测到 RMS/规则端口响应但没有真实许可签出证据
- **THEN** 只显示端口可达，不宣称许可已经可用或签出成功

### Requirement: 虚拟机实验按隔离任务执行

虚拟机插件 SHALL 将模拟 Host 测试与真实虚拟机测试区分，绑定选定 VM、快照、目标产品和输出目录。启动、关机、快照还原等状态变更 MUST 在显式运行的计划中列明；插件加载、发现或预览不得触发这些动作。

#### Scenario: 只查看虚拟机测试计划
- **WHEN** 用户查看实验矩阵或预览任务
- **THEN** 不启动 VM、不恢复快照、不更改许可或工程数据

#### Scenario: 虚拟机任务超时
- **WHEN** 已提交的虚拟机任务超时且结果尚不可确认
- **THEN** 报告结果未知并保留关联标识和日志位置，不自动恢复快照或重复运行
