# 查阅资料

先查询内置完整用法，再查已经配置的资料库。内置指南与发布源码优先；个人资料作为补充，记录它的来源与适用版本。

```powershell
& $cli op invoke builtin.usage --input '{"query":"当前元素"}'
& $cli op list
```

从实际目录找到所需 `knowledge.*` 操作后，用 `op describe` 查看输入。保留结果中的资料库身份、数据库摘要、来源路径和片段编号；片段编号不能当作跨库通用编号。

普通查询和安装不会自动重建资料库。只有明确选择来源、审阅导入范围并授权后才建立或更新索引。来源版本不匹配时，在引用结论前先核对。

资料用于帮助理解问题；是否写文件、启动工程或执行 PML，仍取决于本次任务授权。
