## 同一工作空间的四个入口

| 页面 | R2 信息组织 | 可以实际操作的预览内容 |
| --- | --- | --- |
| 启动工程 | 主导航、最近工程、模块卡片、四个日常字段 | 新建演示配置、选模块和产品、预览启动信息、查看记录 |
| 知识库 | 分类、笔记列表、阅读区三栏 | 标题/标签/正文搜索，新增/编辑/归档/恢复，修订回看和恢复，资料源登记/编辑/模拟索引/移除/恢复 |
| 设置 | 用户目录、外观、启动行为、凭据、预览说明 | 推荐路径、变更预览与确认，紧凑间距、减少动态效果，启动策略与日志偏好，凭据清除二次确认 |
| DocFX | 学习首页、左侧指南、正文、右侧本文目录 | 七篇独立指南、全局搜索、文章切换、收藏与书签、代码复制、API 概览/参数/相关文档、更新记录 |

应用页继续演示按钮绑定、参数、合成 ELDATA 表格、筛选、下标排序、分页、CSV 导出与超时状态。32 条数据均为合成样例，不能据此声称 AVEVA 大数组已通过复验。

## 可复刻的评审路线

1. 打开知识库，新建一篇笔记并保存；修改正文，再从修订记录恢复旧内容。恢复生成新修订，原历史仍在。
2. 归档笔记，进入归档并恢复；搜索不存在的关键词查看空状态。离开未保存编辑会确认，浏览器返回也受保护。
3. 在资料源中添加示例路径，重复路径会提示；模拟索引后移除登记，再从已移除来源恢复。
4. 在设置修改用户根目录，先看变更预览，再确认；修改只作用于演示状态。账户与凭据中清除密码需再次确认，取消保留原状态。启动页取消“记住本机密码”不清除已有凭据。
5. 从 DocFX 搜索“目录”，打开“用户目录与升级”，收藏后在书签中找到；打开 API 参数页核对现有 `MatchLargeArr` 的 ARRAY、STRING 与 ARRAY 返回值。
6. 应用页读取合成数据，筛选 `880.500` 应得到下标 05；在绑定中打开模拟超时，失败时不保留成功结果、不自动重试。

## 设计与兼容边界

展示名称统一使用 Phayton。`PhaytonObjectWalker` 方法、原环境变量、运行目录、可执行文件和注册标识保留；`Documents / PhaytonWorkspace` 仅为预览路径。实际用户目录行为见[用户数据与知识库](user-data-and-knowledge.md)。

预览不访问真实凭据、不连接 IPC、不启动 AM/E3D、不读取本机资料。页面状态仅保存在内存；刷新恢复示例。复制示例和下载合成 CSV 是用户在浏览器里主动触发的操作。

浅色基础、80px 主导航、260px 上下文区、白色内容面板与蓝色主要动作延续 R2；在窄窗口中响应布局，独立宽屏评审器保留 1600px 的完整内容并支持缩放。CSS 轻量过渡遵循系统减少动画偏好，也提供显式开关。自绘标题栏仅为浏览器视觉预览，原生窗口边框与 WebView 集成仍待后续实施。

正式 DocFX 只新增本说明和资源入口，主题不替换。页面示例不是正式 API 全量目录；真实契约继续由现有源码和 XML 注释生成。历史实测与本次设计验证分别保留，最新大数组卡顿待验状态不因本批预览而改变。
