# Spec Delta

## Purpose

让管理器负责可追溯的 Yuzuha 运行文件部署和产品环境登记，支持独立复制目录及引用管理器自带运行文件两种布局。在多版本 AM/E3D 共存时，把目标、变更、备份和回退范围展示给用户，并保护独立用户资料。

状态：候选，未 sync/archive。有效入口/环境选择、独立 EVARS 服务、两种运行布局、冻结计划与条件恢复已实施并通过隔离故障矩阵；MCP 注册不是现行部署前置条件。新部署 Feature、完整 Host/PML/桌面发行包、实际本机更新差异/占用/回退预览仍未交付，当前 Manager CLI 包不能替代完整安装包。当前源码见 [设计定位](../../design.md#现有源码与测试定位)，范围见 [实施验证](../../implementation-verification.md)。

## ADDED Requirements

### Requirement: 运行文件支持两种显式部署模式

管理器 SHALL 支持复制到用户选择的运行目录，以及引用管理器安装目录中的受管运行文件。两种模式 MUST 在应用前展示绝对路径、产品配置、框架、来源版本和文件差异；用户知识、笔记、配置和记录 MUST 独立于可更新载荷。

#### Scenario: 选择目录复制
- **WHEN** 用户选择独立 Yuzuha 运行目录并预览部署
- **THEN** 展示新增、替换、跳过及备份项，仅在应用该计划后复制选定载荷

#### Scenario: 引用管理器自带运行文件
- **WHEN** 用户选择安装目录内引用模式
- **THEN** 环境登记引用该模式下明确存在的受管路径，不再复制第二套运行文件；用户资料仍保留在独立数据目录

### Requirement: 修改选定产品实际生效的 EVARS 文件

管理器 SHALL 根据安装记录及启动链选择有效的 INIT；AM/PDMS 只有确认没有适用 INIT 且实际使用 BAT 时才选择 BAT。写入 MUST 保留编码、换行和原有非托管内容，先备份后更新唯一托管段，不得因 INIT 不可读而转改 BAT。

#### Scenario: 多个产品并存
- **WHEN** 用户选择 E3D 3.1 部署而本机还有 E3D 2.1 与 AM
- **THEN** 只预览和更改该 E3D 3.1 的有效环境文件，其余产品保持原样

#### Scenario: 无权限或预览后文件变化
- **WHEN** 目标文件不可写，或内容已不同于冻结计划
- **THEN** 拒绝未获准的更改并返回准确目标与原因；不写其他版本，不把配置失败显示为成功

### Requirement: 部署与环境登记可恢复且可验证

管理器 SHALL 记录载荷和环境文件的前后指纹、事务阶段、备份与结果。失败 MUST 尝试恢复本次已应用修改，并报告无法恢复项；旧资料和非受管文件不得被清理。目录命名或迁移 MUST 保持引导程序能够解析运行根。

#### Scenario: 文件复制成功但环境登记失败
- **WHEN** 环境文件写入阶段失败
- **THEN** 回退本次文件和环境修改，或明确报告恢复待处理；不得留下伪造的完成记录

#### Scenario: 自定义运行目录名称
- **WHEN** 用户选择不含默认引导标记的目录名称
- **THEN** 预览明确的引导适配，或以可解释错误拒绝部署，不能仅复制文件后宣称可用
