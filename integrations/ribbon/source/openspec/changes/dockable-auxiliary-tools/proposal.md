# 单窗口优先与可拖出辅助工具

## Why
工具默认停靠，减少弹窗和遮挡；职责冲突或需并排对照时才拖出非模态辅助窗。不能用分割线把高风险写入和日常编辑混在同一区域。

## What Changes
- 先完成 FigCraft 停靠态、单屏并排态，再实现 WPF。
- 全局工具页签可拖出、通过入口浮动、停靠；同一控制器与内容不重建。
- 关闭辅助窗默认停靠，重复打开激活已有窗；支持单屏自动排列。
- 功能定义编辑复用当前 UIC 的内嵌视图，历史/管理复用全局工具页。
- 写入确认继续独立显示；不修改后端服务边界。

## Impact
仅调整 WPF 视图承载与生命周期，保留文件状态、草稿、增量撤销和查询结果。前后端继续通过既有 HTTP 契约通信。
