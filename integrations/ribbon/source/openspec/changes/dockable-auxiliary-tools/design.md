# 停靠与浮动

FigCraft 源为 design/figcraft/workspace-docking-0.8.figcraft，基于 0.7 的实际界面结构保留原画板，新增默认停靠和 1920×1080 单屏对照稿。首先完成并检查设计，再进入 WPF。

文件编辑不默认拆窗；功能定位、UIC/XML 查询、批量部署、登记变更和历史页是可拖出的辅助工具。拖动工具页签离开标签栏，或通过拖出入口/右键菜单浮动。复用同一个 UIElement 和控制器，在 TabItem 和浮动 ContentControl 之间重新承载，避免刷新导致筛选、勾选或结果丢失。

浮动窗为有主窗 Owner 的非模态窗，不占新的任务栏入口。标题栏提供停靠和单屏排列；关闭按钮回收至原标签。拖回主窗标签区域也可停靠。操作正在写入时不改变承载位置。主窗关闭后清理辅助窗。

单屏排列以系统工作区为边界，宽屏左右排列；不足时上下排列，必要时临时放宽主窗最小尺寸，最后一个浮动工具停靠后恢复。默认浮动位置在工作区范围内。现阶段自动排列使用主屏工作区，不持久化跨显示器布局。

功能定义复用既有功能库详情视图及待应用字段保护，而非再建编辑窗；历史/管理改为内嵌工具页。部署、登记写入的核对确认保留模态步骤，减少写入误触。

验证完成：完整 WPF 原生回归通过，证据 .runtime/desktop-smoke-Kh9iar/；新增断言包括同内容/控制器、主窗仍可用、重复打开、单屏无重叠、关闭停靠、最小尺寸恢复、内嵌功能定义与历史单例。架构检查、TypeScript 检查与 OpenSpec 严格校验通过。0.8 已默认以单一主窗启动，没有自动对真实 UIC/XML 执行写入。
