# PRD · 产品需求文档（压缩初稿）

## 能力与结果

Windows WPF/.NET10 工作台管理应用、登录和工具。[接入范围](INDEX.md#范围与状态)。

| 能力 | 结果 |
| --- | --- |
| 配置 | 保存、复制与提交回执 |
| 启动 | 独立环境、阶段及会话证据 |
| 监测 | 带身份和时间的资源状态 |
| 交付 / 变量 | 预览、确认、写后核验、恢复 |
| 分享 / 迁移 | 非秘密配置或独立迁移副本 |

## 验收边界

保存、受理、窗口和登录分别反馈；旧计划失效后重新确认，取消等待不撤销已发生写入。用户、优先级、平台矩阵、性能与升级策略待确认；真实登录、许可及 UAC 另验。迁移须保留原资料。
