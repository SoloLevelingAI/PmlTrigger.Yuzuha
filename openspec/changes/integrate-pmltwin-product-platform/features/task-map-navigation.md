# 从任务主干到细节分支的动线契约 · 2026-11-01

## 总体契约

默认入口是任务地图，而不是先读完整资料再寻找操作。主干为「当前情况 → 选择目标 → 当前步骤 → 结果与下一步」；Feature、内部Script、完整契约、静态方法和证据是可往返的分支。Web是只读说明，Desktop才有实际操作；地图位置不代表执行进度、可用性或验收成功。继续保留原27项未完成业务任务。

首屏应回答：这是什么任务、我在哪里、下一步去哪里。原始数量、G/R/B/T/S索引、生成摘要、维护统计不得挡住任务入口。作品集保留克制配色、明确主次和留白；实际渲染分别记录代理复核、用户未认可和业务验证，不以新框线或测试通过宣称美观完成。

## Feature细约

### 同源任务地图

共享render model增加`taskMap`，由已校验元数据生成。固定`schema=contract-task-map/1`，稳定项目/Feature/步骤节点及有类型的关系；每个节点保留原entityId、flowId/stepId（适用时）、摘要、交付、限制和来源引用。分组仅为阅读归类，不成为执行顺序。18个Feature全部可达；14个Script及191条来源映射仍可进入完整分支。

只有元数据登记的launch/ribbon/migration三条流程生成步骤与next/uncertain/recovery关系；无流程的Feature明确说明未登记步骤。重复使用同一Script的多个步骤保留独立stepId。文档入口和产品入口分开；未登记真实路由的产品入口注明不可用及原因，不造执行按钮。公共地图不携带源码或本机凭据，不把静态方法映射当成运行轨迹。

Web与FigCraft使用同一taskMap和token。原生新增聚焦地图参考板，展示项目主干、Feature分支、选中启动四步及契约/方法/证据出口；文字和连接可编辑，明确是静态参考。保留既有画板与原稿，原生失败仍使用lastgood。

### Web主干与支路

项目入口先显示可选择的任务分支；实体入口先显示所属路径、实际流程步骤、当前步骤目标/交付及下一步。选中步骤时保留task/step上下文，同一Script多处使用不丢失位置。提供明确回项目地图、回任务及前后步骤入口；没有next的步骤显示终点或已登记的未知/恢复出口。

正文切换「任务地图 / 完整契约 / 实现方法 / 证据与来源 / 完整目录」分支，仅呈现当前分支，避免所有资料纵向堆叠。切换不执行工程动作、不改三轴状态。完整原文仍在两次明确选择内可达；统一摘要/详情只控制当前及后续进入的内容，不强制打开所有分支。目录可渐进展开，不将32项内容同等铺满首屏。

URL记录branch、flow及step（稳定原ID）；保留旧entity/feature/view/detail/catalog/method/section与筛选。旧section深链先进入对应分支，再展开必要祖先；刷新、返回、修订更新保留有效位置，删除时回最近有效任务/项目并提示。目录和本页标题只列当前可见分支，不失效或偷抢焦点。独立导入和草稿继续隔离。

### Desktop主干

Dashboard保持默认首页；无运行会话时主入口「启动工程」，有进程但Host不可用时「查看连接原因」，可用Host但未明确目标时「选择操作目标」，新鲜且明确的目标就绪时「选择任务」。启动其他工程保留为次入口。自动发现不暗选目标、部署Host或执行PML。

用户明确进入目标选择时执行只读刷新；按精确PID/启动时间提示候选，多候选不默认选第一项。用户选择并核验成功后进入任务选择，清楚展示当前目标和前置条件。对象读取、Form/Gadget、数组读取、注册函数有明确入口；只导航，不自动查询、授予权限或调用。结果在操作附近显示摘要及完整回执出口，允许回任务地图；unknown继续观察原编号，不重放。输入、授权、协议限制和忙操作保持。

## 内部Script细约

| 单元 | 输入/前置 | 方法与副作用 | 校验/回执 | 失败恢复 |
|---|---|---|---|---|
| render-model taskMap | 校验后的公共元数据/原流程 | 稳定节点、有类型边、入口可用性；只投影 | 全Feature覆盖、引用/step唯一、同摘要 | 非法关系拒绝，不猜执行顺序 |
| Web导航 | taskMap、branch/flow/step/旧URL | 逐层选择与分支切换；仅阅读状态 | 首屏入口、当前位置/下一步、可返回 | 删除回退、旧锚点选正确分支、焦点恢复 |
| 原生适配 | 同一IR/token | 生成静态可编辑地图板 | 同实体/step/交付/边界 | 失败不共同发布 |
| Dashboard入口 | 新鲜监测快照/明确目标 | 按状态提供下一入口；只读刷新 | 无暗选、身份精确、主CTA可解释 | 失联清理，未知保持 |
| 会话任务导航 | 明确核验目标/现有业务控件 | 任务选择、操作/结果局部定位 | 全任务可达、输入保持、不隐式执行 | 忙态阻止冲突，unknown不重放 |

## 验收与汇总

1. Web真实浏览器在1440/1024/390两主题首屏可选任务，不需越过完整契约或统计；选择启动→任一步→契约/方法/证据→返回仍在原步骤。验证重复Script、多流程/无流程、旧深链、键盘/历史/修订恢复。
2. 原七字段与全部目录/规范入口保真，任务地图来自同一IR；真实FigCraft地图板可编辑且同摘要，Web只读与原生静态边界明确。
3. Desktop单元/原生界面验证各状态CTA、明确核验后任务入口、四类任务导航及就近结果；保留现有会话和unknown语义。实机E3D不重启、不重复登录或写工程，验证导航与既有可用性。
4. 总分总：项目地图选任务 → Feature步骤定位 → Script契约/方法/证据分支 → 返回原路径；资料完整性服务任务路径，不成为首屏负担。
