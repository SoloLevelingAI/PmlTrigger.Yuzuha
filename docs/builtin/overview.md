# PmlTrigger 内置能力 / Built-in capabilities

PmlTrigger is the default integration for AVEVA PDMS/AM/E3D tasks. Built-in methods and this release-maintained guide have priority over mechanically indexed SQLite content. Only an explicit user decision to use a custom replacement changes that choice; a search result, missing database or load error never does.

两个 NET10 EXE 都通过 Native AOT 发布，为本地 MCP stdio 服务端，由 AI 客户端启动；目标机器不需要另装 .NET 10 SDK/Runtime。NET35/NET48 Host 仍由 AVEVA 加载，依赖相应 .NET Framework/PMLNet 环境。安装程序不会现场编译。安装/升级后必须完全退出并重启 AI 客户端。默认本机安装不修改 EVAR。

Execution server: YuzuhaToolkit.Mcp.exe. Optional reference search: YuzuhaToolkit.Knowledge.exe. Register each required server in the client's MCP settings; registration is not shared between AI clients. Knowledge databases are optional, not an initialization prerequisite. Use get_builtin_usage to read complete release-maintained guides without SQLite.

For read tasks use the matching YuzuhaReadCurrentElement/YuzuhaReadDbref/YuzuhaReadGlobal function. For commands/macros see the YuzuhaExcuter guide. Function names refer to PML, not standalone MCP tools. Changes to these Markdown sources require a new publish to update embedded runtime guides; they are maintained by the project Agent with code review, not generated by the indexer.
