# ION桌面任务、页内方法与主题色

ION是当前优先视觉方向：酸性编辑式排版，辅以克制的玻璃和金属拟物。面向开发者，先设计电脑上的任务阅读动线；手机后续可独立布局，共用语义配色和契约数据。

## 总体：在当前工作区完成阅读

打开[ION](http://127.0.0.1:19440/ion/index.html)，选择Feature后进入桌面工作区。左侧保持所属任务、登记流程和当前步骤，右侧切换摘要、完整契约、实现方法、验证证据。长内容在各自区域内滚动；查看源码不会把路径推走。

顶部面包屑按**主页 → Feature → Script → Script Method**排列，可以直接回上层。步骤是另一条流程路径，留在侧边，不混作归属层级。方法没有明确Script绑定时显示缺少关联；静态关系到达的其他方法注明关联阅读，不猜所有者。

每级名称旁的下拉箭头可直接切换同级，不用先回上一层。Feature菜单列项目全部Feature；Script菜单只列当前Feature的关联Script；方法菜单只列当前明确Script的精确绑定根方法。可以搜索名称或ID，方法带完整签名提示，当前项有文字标记。未登记和搜索无匹配分别说明；过期或未就绪的方法不保留旧候选。

同级切换保留配色和当前阅读栏目，切到新Feature/Script时清除旧步骤和方法正文，再按新目标核对。重选当前项仅关闭菜单。方向键移动、Enter确认、Esc关闭并返回触发按钮，Tab可自然离开；直接切换新实体后焦点到标题。Feature/Script支持浏览器前后退和刷新，方法沿用面板内选择，不新增精确方法书签。

## 分支：契约、实现与验证

完整契约仍保留Feature原字段和Script七字段。实现方法在同页展示精确绑定、签名、XML说明、源码行/摘要和直接静态调用关系。已登记的DocFX成员也在方法区内显示为静态说明；目录与搜索脚本不启用。没有绑定、快照过期或内容等待共同发布时，显示真实原因并隐藏旧正文。

实现状态和验证范围分别判断。Script当前继承的Feature证据不能称为Script独立通过；例如Ribbon外观加载验收不能替代pending脚本的独立验证。证据区标明关联范围、环境、时间和排除项。

从工作区关闭方法回摘要；从完整契约对话框打开方法，关闭后回原契约及触发按钮。相同Script切流程步骤保留方法、展开和滚动。异步旧响应不写入新任务。

## 配色：六种同构主题

| ID | 名称 | 外观 |
|---|---|---|
| lime | 离子柠檬 | 原荧光柠檬与纸张 |
| cyan | 冰川青电 | 冷青与清晰浅底 |
| violet | 紫外频段 | 紫色强调与浅底 |
| orange | 熔橙航道 | 暖橙强调 |
| rose | 脉冲玫粉 | 玫粉强调 |
| graphite | 石墨夜航 | 深色石墨与荧光强调 |

导航中的“配色”支持键盘及本机偏好保存，URL显式`theme`优先。切换更新整套纸面、墨色、边界、金属、玻璃、阅读器和方法颜色，不重建内容或改变验证状态。颜色源在`themes.json`，生成CSS有漂移检查。

## 汇总与边界

从任务路径定位上下文，按需切入契约、真实方法和证据，再沿面包屑或步骤继续阅读。主要验收为1920×1080、1440×900，1024×768复核紧凑桌面；手机仅保留基本访问，独立布局仍待设计。FigCraft深化由用户指定区域，原27项业务未完成任务保持不变。
