# 评审 测试与 HTML 应用的实现边界

评审迁移、桌面测试执行和 HTML 应用管理是已提出的功能方向。当前 WPF 保留设计页面；HTML 管理器另有独立本地入口。功能目录的“计划功能”表示实现状态，不能根据页面存在或目录登记判为已交付。

## AI 草稿评审与迁移

AI 的试验 PML 放在独立 `tests/ai-pml/<任务名>/`，不直接覆盖原生 PMLLIB/PMLUI。一次实质变更记录目的、差异、契约影响和实际验证。由一名人工审核对应源码版本和证据，批准后迁移。现有复制、哈希和备份能力继续复用，新增的是批准快照、目标文件、迁移回执和恢复记录。

审核通过、登记、允许调用、文件复制、PML 重加载、已加载版本核验与实机验证分别记录。改变源码或契约后重新评估旧审核是否适用。此页和目录元数据不授予调用许可，也不执行迁移。

## 桌面测试执行中心

复用 `scripts/run-documented-test.ps1` 和 `test-map.json`，按真实 ID 核验源码后执行。GUI 需要展示提交、环境、执行数量、结果和证据路径；失败、跳过、零匹配、未执行、历史结果及未知结果分别呈现。GUI 操作尚未接入，当前通过 DocFX 详情复制命令执行。

## HTML 应用管理

独立本地管理器已经实现分类、按钮、参数与真实 IPC，见[操作说明](../html-app-manager.md)。WPF 的 Web 应用页面仍未接入；第三方 HTML 包来源、远程分发与更新生命周期尚待扩展。开发 DevHost 继续仅提供预览，其接口没有增加执行能力。

2026-10-23 已补开发阶段的数据出口：`pml-data-table.mjs` 将既有 IPC 返回数据生成本地 HTML 快照，支持筛选、导入 JSON 和导出 CSV。复制、重载和验证已有独立开发脚本及 E3D 实测；独立 [HTML 管理器](../html-app-manager.md) 已接持续调用桥，现有桌面集成仍未实现，见[开发链路](../pml-development-flow.md)。
