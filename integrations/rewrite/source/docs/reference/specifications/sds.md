# SDS · 软件设计规格说明书（压缩初稿）

## 身份与契约

字段和签名见条目中的编译 API；本页列关键不变量。

| 协议 | 规则 |
| --- | --- |
| CommitId | 核对原提交、修订与回执 |
| OperationId | 同摘要返回原操作；冲突拒绝；租约准入、序号追加 |
| 启动 | Monitor/Marine 各用原协议，秘密插槽临时解析 |
| 资源 | 冻结身份、策略与证据新鲜度匹配 |
| 部署 / 变量 | 确认摘要、基线比较、检查点与写后核验 |
| 分享 / 迁移 | SchemaVersion 3、CommitId / 独立副本、OperationId |

## 诊断与边界

仅 `GET /health`、`GET /api/operations`；窗口不证明会话。秘密不作普通序列化。内部存储不承诺跨版兼容；容量、保留和回退策略待确认。[共用验收边界](INDEX.md#范围与状态)。
