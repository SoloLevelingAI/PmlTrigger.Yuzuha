## Reproduction

Restore projects using the repository NuGet.Config, publish both .NET 10 projects to runtime/net10, and run the two tests above. Native AOT publishing needs the C++ native build toolchain. To run the tests against an extracted candidate, set YUZUHA_TEST_PACKAGE to its absolute root. Test data is created outside that package. The source test currently uses the available prebuilt profile layout for the profile configuration checks.

Run `python scripts/Package-Release.py` once from a fresh output state after publishing. The packager creates an agent ZIP, a source ZIP and SHA256 manifests, excluding local DBs, experience, trust and proprietary reference assemblies from the agent package.
