# Design

## Feature 边界与合并方式

| Feature | 只读评审职责 | 写入边界 |
| --- | --- | --- |
| Editor | 编辑器 Ribbon、文件标签、结构树、侧栏、预览 | 主工作区与折叠/收起状态 |
| Editing | 表头和行中心、Tooltip、单项/批量、当前文件/跨文件 | 按钮停靠页、查找浮窗与批量状态 |
| Registration & Deployment | 版本、来源保护、登记路径、备份与目标预览 | UIC↔XML 与部署工具状态 |

三个真实 Claude Code 进程只具备 Read 工具，不连接 FigCraft MCP。三个评审的原文与逐项合并判断保存在交付目录 `reviews/`。执行期间只有根写入者通过 FigCraft 原生命令串行修改一个工作副本。

## 视觉原则

延续窄蓝标题栏 `#254E7A`、白色内容面、浅灰工作区、低饱和选中和 1 px 细线。保留 UIC 自带图标，不把这些内容图标统一染成品牌色。字号以 12 px 正文、11.5 px 次要文字为主；不整体缩小主窗去塞内容。规格、尺寸与设计样例说明放在产品帧外、作品集板和 README 中。

默认 1280×800 与 1100×740 仍为完整 106 px 命令 Ribbon。手动收起后保留 44 px 命令条、标题栏撤销/重做、更多命令浮层和展开入口；两对状态保持同尺寸。更多命令补齐被收起的入口。本轮未把每个菜单项实现成真实业务操作。

## 编辑语义

树、预览和表格活动行指向当前按钮；右侧标题标明「单项」。复选框代表批量集合，勾选本身不会触发修改。批量入口切换当前右侧区域，不增加业务窗口；仅勾选并填写的字段被应用。示例只改两个按钮的 Tooltip 正文，形成一条可撤销操作。

表格固定列左对齐，名称/Group 30 px 块置于 36 px 行中心，图标与复选框居中，单行 Macro/Tooltip 中心误差不超过 0.5 px。Tooltip 表格单元格显示正文，详情区保留标题与正文分区。狭窄列使用省略和滚动，不缩小字号。UIC 小按钮按三行纵向填充，第四个另起一列，保留 `[3,3,3,3,1]` 样例排布。

「已打开 3 个」查找模式整体只读；定位后跳转所属文件进行编辑。否决将当前文件混入跨文件模式后又开放局部编辑的建议，避免同一结果表中出现两种修改权限。

## 登记与部署

XML 页以安装路径 + XML 路径区分同名模块；产品版本用文字和低饱和颜色共同区分。来源列区分部署器与原生，原生详情明确保护原因，不能移除。部署器项也不能在观察页直接删除，需要管理登记时预览确认。

部署页同时列出两个勾选目标的完整路径、结构、关联登记和校验信息。原生项复选框呈禁用态，不出现在写入预览。覆盖现有 UIC 时在同目录备份；首次目标写入可来自当前打开的编辑草稿。现有 XML 引用保持不变，新登记另行处理。

## 设计系统与原型边界

- 1 个 Light 集合，18 个颜色/间距变量，6 个文本样式。
- 4 个组件变体集合（按钮主/次操作、输入、文档 Tab），共 20 个变体，另有 1 个紧凑按钮组件及实际主窗实例。
- 19 个顶层设计帧，包括产品状态、控件库与作品集板。作品集中的产品画面由原生图层复制组成，保持 1280×800 原尺寸。
- 原型支持主要导航、同尺寸展开/收起、批量应用/撤销/重做示例、浮动返回与停靠预览、来源详情切换、部署结果。
- 不执行真实导入、写盘、连续拖动、布局持久化或真正的撤销数据结构；业务命令和性能仍需后续 WPF 集成验证。
