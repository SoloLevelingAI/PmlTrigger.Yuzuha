## ADDED Requirements

### Requirement: 默认多文档 Ribbon 编排
编辑器 SHALL 在打开 UIC 时默认显示 Ribbon 编排，每份 UIC 一个文档标签，各自保持选择和增量撤销。

#### Scenario: 打开两个文件
- **WHEN** 用户打开两个不同 UIC
- **THEN** 工作区显示两个编排文档，不为每个文件重复创建功能库和关系查询导航

### Requirement: 工作区单例功能定位
功能定位 SHALL 以独立单例页面聚合多个 UIC，保留文档及实际引用身份。

#### Scenario: 同名同 ID 的两个来源
- **WHEN** 两个 UIC 含有相同名称和 ID 的功能，用户定位其中一个结果
- **THEN** 激活对应文件并选择实际引用，不误选另一文件；再次打开定位工具复用同一页面

### Requirement: 工作区单例双向关系查询
关系页 SHALL 在同一页面支持 UIC 查 XML 和 XML 查 UIC，按完整规范路径去重，明确范围与未解析项。

#### Scenario: 同一 XML 重复登记
- **WHEN** 同一 XML 多次登记同一 UIC
- **THEN** 正反查询只计算一个关系对，完整路径可查看，查询不写入文件

#### Scenario: XML 未覆盖扫描范围
- **WHEN** 用户指定尚未覆盖安装中的 XML 路径
- **THEN** 页面提示结果不完整并提供扩展扫描范围入口，不将空结果作为没有引用的结论

### Requirement: 柔和圆角与真实视觉验证
共享控件 SHALL 使用统一圆角与细边框，卡片子内容正确裁切，键盘焦点 SHALL 保持可见且可操作。

#### Scenario: 内容填满圆角面板
- **WHEN** 白色表格或侧栏填满卡片
- **THEN** 子内容不覆盖圆角，表格内容可滚动，滚动视口不越出窗口，完整路径仍可查阅
