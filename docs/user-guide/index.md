# 从你要完成的任务开始

Phayton 在本机连接 AVEVA 与 AI 客户端，帮助开发 PML、读取工程数据并核对操作结果。

| 现在要做什么 | 从这里开始 | 做完后核对什么 |
| --- | --- | --- |
| 刚安装，准备产品环境 | [安装与环境准备](install-to-operation.zh-CN.md) | 所选环境、冻结预览和本次回执 |
| 已打开工程，确认连接目标 | [核验工程会话](connection.md) | PID、启动身份、模块与当前核验结果 |
| 编写、加载或验证工具 | [开发与加载 PML](pml-development.md) | 已审阅文件范围、加载结果和验证回读 |
| 阅读对象、定位模型问题 | [读取与核查工程](inspection.md) | 数据来源、读取边界和有无截断 |
| 操作报错或结果不明确 | [核对回执与恢复](recovery.md) | 原操作编号、实际状态和可恢复范围 |

建议先完成环境准备与会话核验，再进入开发或工程核查。操作期间保留 JSON 回执和退出码；超时或断线后先核对实际结果。

AI 客户端需要[接入本机 CLI](ai-client.md)。查询内置用法和已有资料可从[查阅资料](knowledge.md)进入。

本指南随应用提供。实现细节、完整 API、源码关系和测试目录收在独立的[开发参考](developer-reference.md)中，按需手工获取。
