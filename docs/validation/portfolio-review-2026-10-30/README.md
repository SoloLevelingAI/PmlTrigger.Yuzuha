## 函数能力核对

已有通信 CLI 操作：`pml.function.register`、`pml.functions.list`、`pml.function.permission`、`pml.function.invoke`；旧 GUI 有登记、签名、源码检查、授予/撤销、预览与调用入口。登记保存本机源码 SHA256，参数为 STRING/REAL/BOOLEAN 标量；默认禁止调用，重登记关闭许可，源码改变拒绝调用。

本机登记、保存的调用许可、人工信任建议、AVEVA 当前实际加载版本是四件事。登记不会自动加载函数，源码哈希拒绝不等于持久修改旧许可标记；不能从本机记录推定会话已加载对应版本。

**新 Manager CLI 的52项尚无统一函数入口。** 目前仍经通信 CLI/旧GUI使用；该整合缺口与新界面须一并闭合，不能描述为新管理器已经全功能替换旧工作台。
