# 界面设计

`LaunchDesk-fusion-v2.figcraft` 是原生可编辑设计稿；同目录 PNG 为页面、弹窗、紧凑布局和组件导出。`overview.png` 为总览。

应用在 2.0.1 中完成整体视觉与布局对齐：220px 固定侧栏、统一页头、工作台摘要及详情、工具来源与目标分区，以及并排导入导出。真实应用按本机配置显示内容，条目数量和运行状态可与设计中的示例不同。

设计参考尺寸为 1440×1000，同时验证 1180×800 与 1120×740。列表可在区域内滚动，保存、启动和部署操作保持可见。

2.0.4 补齐窗口外框：圆角、细描边和 Windows 11 系统阴影；最大化时采用直角并收起描边，还原后恢复。内容位置与原有页面布局保持一致。
