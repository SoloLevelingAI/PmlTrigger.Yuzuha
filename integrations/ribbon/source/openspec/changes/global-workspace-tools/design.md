# 页面归属与视觉调整

## 结构

标题栏 → 全局命令 → 工作区标签 → 当前内容 → 状态。

| 页面 | 数量 | 范围 |
| --- | --- | --- |
| Ribbon 编排 | 每个打开的 UIC 一页 | 单文件预览、引用布局、详情与撤销 |
| 功能定位 | 工作区一页 | 收集 N 个 UIC，搜索并定位实际引用 |
| UIC ↔ XML | 工作区一页 | UIC 找 XML、XML 找 UIC，同页切换方向 |
| 批量部署 | 工作区一页 | 选择 N 个文件生成部署计划 |
| 登记变更 | 按需复用一个工具页 | 显式预览与确认，查询页不直接写文件 |

首个文档默认 Ribbon 编排。每文档保留选择、撤销和视图状态；全局工具保留自己的来源集合、筛选与结果，不因切换活动 UIC 重建。再次打开工具激活同一标签及控制器实例。

## 定位与查询

功能定位身份是文档/来源、buttonId 和实际引用对象。跨文件相同名字或 ID 不能合并编辑；定位前核对引用是否还存在，已变更时提示刷新。完整路径在选中详情和提示中展示；表格以单行省略避免长路径撑高所有结果。

关系页按规范完整路径对 UIC/XML 对去重。正向显示一个 UIC 对应多少不同 XML；反向显示一个 XML 引用多少不同 UIC。直接给 XML 路径只查询当前已知扫描结果，未覆盖安装必须提示范围不完整；提供 mon.exe 扩展扫描范围。读取失败、未解析环境变量和未知版本明确显示，空结果不得宣称没有登记。

添加 UIC 后保留已收集来源并回到同一工具；只读查询不更改 UIC/XML。登记变更仍走后端及备份确认。

## 视觉

统一资源：控件半径 8、弹层 10、面板与表格 12、复选框 4，普通细线 #E4E9F1。不把复选框画成单选圆圈。卡片和表格裁切子内容，避免圆角被子面板白色背景盖掉。

保留悬停、按下、选中、焦点和禁用状态。全局命令按行对齐；Ribbon 文档减少一条重复导航栏；关系详情按需展开，优先显示结果列表。长路径、选中位置和来源信息完整可查，不靠缩小字号容纳。

新设计稿四个状态：默认编排、全局定位、关系正向、同一关系页反向。旧画板保留，新状态可点击跳转。设计元素边界校核无画板越界；实际 WPF 另做 1050/1280/1440 采样。设计稿是示例数据，真实计数以扫描为准。

## 实现与验证

FunctionLocatorPage 与 RegistrationExplorerPage 为独立工具控件；GlobalWorkspaceTools 创建和复用控制器。DocumentSessions 管理全局标签与文档标签的区别。定义编辑改为选中对象的模态详情；旧功能库/检查视图仅用于内部兼容回归，不作为用户的默认导航。

WorkspaceToolsVerification 覆盖默认编排、工具单例、同名同 ID 的两 UIC 精确定位、真实三 XML 去重、双向数量、错误提示与只读字节不变，以及圆角和焦点。滚动内容允许超出视口，但滚动视口必须留在窗口内，并记录未裁剪内容边界与可见交集。光学中心和平衡仍结合实际截图人工复核，不能用坐标通过代替。

当前最小宽度 1050 DIP。768 与独立多 DPI 矩阵尚未完成；当前系统原生 DPI 会记录在现有回归报告中。
