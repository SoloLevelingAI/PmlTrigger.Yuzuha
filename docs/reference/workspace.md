# 工作台

正式版 0.3.4.2：启动配置已接共享服务；未完成交互见[待定清单](features/planned-tools.md)。

1. 新建配置，选择安装、产品、模块，填写工程/用户/MDB；LaunchDesk 非前提。
2. 产品、收藏/最近下拉与输入搜索组合筛选。AM 无 DESIGN；安装发现不代表许可/登录成功。
3. 编辑→预览差异→保存；显示新修订。重新读取/重开保留值；配置用于下次启动。
4. 历史→预览→确认恢复；产生新修订，只改目标配置，不恢复密码或覆盖其他项。
5. 外部修改触发冲突，保留草稿；重读比较。切换/关闭前处理未保存修改。
6. 启动与 Host 核验分别反馈；写入、启动、PML 执行分别授权。

凭据存当前 Windows 账户库；配置只存引用。取消记住密码不删除已有凭据；在设置明确清除。日志/预览脱敏。许可/环境只传子进程，不改系统 EVAR。

部署按源/目标哈希预览，备份后复制，再加载/验证；失败或未知停止、不自动重发。开发步骤见 [PML](pml-development-flow.md)，原生自动化见 [CLI](cli.md)。Web 应用使用独立本地服务，无内嵌 WebView。

已验证配置服务/控件使用隔离合成入口，不等于模块实机可用。官方默认知识入口、PML 自动发现及三任务联动尚未闭合。

工具日志现支持状态、操作与输入组合筛选；条件重置恢复当前保留范围，空结果不显示旧详情。
