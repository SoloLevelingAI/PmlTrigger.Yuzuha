# 续作契约与并行边界 · 2026-10-31

基线：PR #13，`39e12f7261891003dfe99594fe5c5e481fe7ac4d`。用户要求先规定契约、细化再实现，并授权 Sol 子代理完成剩余任务。本文件是候选契约的实施细化，不迁移 canonical contract，不以本组完成替代平台整体验收。

## 1. WPF 启动（映射平台 3.4、管理器 6.5）

唯一业务后端仍为 Manager 的 LaunchWorkflowService。桌面 SHALL 复用配置修订、launch.plan/execute/observe 的冻结及持久受理规则，不直接调用 LaunchService.Start 或建立第二份操作事实。

- 保存配置不启动；显式执行创建一次 operationId，计划冻结配置修订、入口及 INIT/EVARS 哈希。相同编号及摘要复用已有事实，冲突拒绝。
- accepted 持久化成功后才可启动；success 仅表示入口进程已创建，登录与 Host 保持独立未核验状态。
- unknown 显示原编号及观察动作，不自动新建编号重试；关闭窗口/取消等待不表示撤销已受理动作。重新打开可输入原编号观察。
- 密码仅在本次内存与现有本机凭据渠道流转；不得进入计划、回执、日志或新增操作历史。现有凭据保存仍依用户显式选择。
- 界面显示阶段、稳定 code、非空 message、operationId 与恢复观察入口。入口退出只表示交接待核验，不能当登录失败或工程关闭。

验收：同编号不重复启动、冻结后文件或修订变更拒绝、unknown 观察不重放、秘密不持久化、WPF 使用唯一协调后端、构建及原界面断言保持。Host 全灯态、跨产品实机验收单独记账。

## 2. Ribbon 冻结部署（映射平台 1.3、5.4、5.6）

旧 HTTP v1/管理 CLI ID 保持兼容，不将其仅校验旧目标哈希的语义描述成完整冻结。新增明确 v2 入口只覆盖已有 UIC 的文件更新与选定清单登记，不复制编辑或 XML 引擎。

- preview 输入为 project 及必要模块选择；服务端规范化文档，以权威存储绑定解析路径，校验原生条目保护。输出版本 2 的冻结计划，绑定 documentId、当前历史版本、规范化 project 摘要、目标、前后文件哈希、登记名称、到期时间与计划标识。
- preview 不 Save、Bind 或改 UIC/XML；可保存有预算、有期限的专用计划缓存，这不属于编辑历史或部署副作用。调用方不能自行构造摘要取得计划授权。
- apply 只接计划标识/摘要，服务端重验缓存、历史版本、目标字节、保护及期限；不能在 apply 偷换 project、entryName 或路径。校验失败时不新增工作区修订，不写目标。
- file-update 仅更新 UIC；registration-add 仅修改选定 XML，UIC 及未选 XML 保持原字节。复用既有备份、编码及写入实现；不自动重启 AVEVA，不执行宏。
- 回执分开表达 workspace、deployment、activation。磁盘写入成功只能声明 deployed；activation 为 reloadRequired/runtimeUnverified。后端重启恢复不是 AVEVA 加载证据，AVEVA 进程重启本身也不足以声明 UI 加载通过。
- 不确定写入返回 unknown 及人工核对动作，不自动重放。不得把跨文件/历史记录写入称作全局原子事务。

验收：篡改/过期/缺失计划、预览后修订及目标变化拒绝；拒绝不 Save；选定 XML/编码/备份保持；v1 错误与授权不变；v2 通过 Manager 精确 schema 显式注册；HTTP 临时安装测试与适配测试。不勾选真实加载 7.3 或 Database 接线 5.5。

## 3. 只读迁移预览（映射平台 4.4）

来源为本仓保留的 rewrite/Next JSON 和 Ribbon 工作区格式。适配器 SHALL 只读选定路径，报告格式版本、来源摘要、原始身份、字段及历史映射、秘密剔除与不支持项；不得自动激活、写回来源或切换 Database。

- 明确支持矩阵；未知格式/未来版本/损坏内容返回诊断，不猜测成功。Direct 保留诊断，不变成 Monitor。
- 未知非秘密字段及历史保留；秘密值和可携带授权的凭据引用不得出现在导出预览中。以字段路径报告剔除，不报告值。
- 扫描须有文件数/单文件/总大小限制，拒绝越界路径与链接，不默认递归任意目录。预览返回 activate=false。
- 此接口只为后续迁移提供可审查材料；不建立新的活动配置写者，不替代 4.3 事实仓储或 4.5 切换恢复。

验收：真实来源格式的最小夹具、未知字段/历史保留、秘密剔除、Direct 诊断、损坏及预算拒绝、来源字节不变和无目标激活。
