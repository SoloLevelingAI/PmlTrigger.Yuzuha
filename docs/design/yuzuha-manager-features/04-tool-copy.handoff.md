# 工具与目录复制

状态：独立 Feature 设计稿，生产界面未完成验收。由当前模型设计，未使用或声称 DeepSeek/Zcode 鉴权成功。

只加载本文件、[共用 tokens](tokens.json) 和 [对应设计](04-tool-copy.figcraft)。原生文件含 Screens/States/Foundations；Light、Dark、960 窄窗与状态页分别导出。

## 行为与边界

差异、备份与恢复连在同一记录里。来源和目标内容会在应用前复核。恢复时保留后续外部修改，并明确列出未恢复文件。

后端归属：Manager CLI / Manager.Core。

- `copy.formats`
- `copy.preview`
- `copy.apply`
- `copy.restore`

## 必须验收

1. 未配置：选择载荷和目标目录。
2. 处理中：显示检查、暂存、写入、回读。
3. 目标变化：重新生成差异计划。
4. 解压失败：显示完整性错误和日志。
5. 恢复待处理：列出被占用或外部修改项。
6. 结果未知：先回收回执，不自动复制。

主操作 → 状态审阅页 → 返回主画面有原型链接；它不是后端操作模拟器。参数编辑、真实表单校验、屏幕阅读器与键盘行为需在 WPF 落地后测试，不能从静态稿推定通过。

## 上下文预算

每次只处理此 Feature。回报限“改动、证据、未完成项”；跨 Feature 只共享 token 版本和操作契约。本地修订与源码哈希变更需显式复核；不要同时让多个 AI 编辑 FigCraft。
