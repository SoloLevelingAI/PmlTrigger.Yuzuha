# 读取与核查工程

先明确工程目标，再描述要查看的对象、属性和范围。对大型数组或对象树使用有界读取，检查回执中的截断、错误和继续位置。

| 要读取的内容 | 使用前确认 |
| --- | --- |
| 当前元素 | 选定会话中的当前元素确实是本次对象 |
| 指定元素 | 使用实际 DBREF 或名称，并核对返回对象身份 |
| 已有全局对象 | 全局名称和当前运行环境一致 |
| 原生窗体或控件 | 当前表单、控件名称和工具实际可返回的属性范围 |

当前元素、指定对象和全局对象分别有内置读取用法。先查询 `builtin.usage`，让客户端读取完整指南，再使用实际操作 Schema 发起调用。

把数据事实、静态关系和推断分开记录。例如“两个对象共享某个属性”是数据观察；“因此必须调整工程”还需要结合任务规则核对。

大属性读取可能耗时或无响应。发生超时先确认原调用状态；不要连续发送更大的相同查询。核查得到的问题可交给明确的小范围修改任务继续处理。
