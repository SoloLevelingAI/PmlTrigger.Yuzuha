# 安装与更新

新安装交互默认选择管理器接手：Inno先安装应用、Host、通信与管理CLI及离线文档，成功后可由原交互用户打开“安装与环境准备”。在管理器选择环境、核对旧所有权、预览部署与EVARS，再明确应用和读取恢复回执。完整阶段契约与真实脚本见[从安装到工程操作](install-to-operation.zh-CN.md)。

安装应用不自动接入AVEVA。旧显式 `aveva` / `none` 计划保留原范围；旧环境所有权移交只修改受管记录，不改EVARS。管理器引用Inno应用根，或复制到独立运行根，不覆盖安装器拥有的应用文件。保留知识库，变更前备份，更新检查现有哈希；运行程序需关闭后替换。

| 产品 | Host |
| --- | --- |
| E3D 2.1 | 2.1 / NET48 |
| E3D 3.1 系列 | 3.1.6 / NET48 |
| AM / PDMS | NET35 |

初始化查询 `Current Session`。REHASH 默认关闭，见[启动策略](startup-policy.md)。独立 MCP 禁用，统一用 [CLI](cli.md)。安装完成、进程创建、Host 核验分别验收；当前实机证据限 E3D2.1。

具体安装参数以仓库 `installer/INSTALL.md` 与安装器预览为准；不发布旧包、旧视频和历史设计副本。
