# 安装与更新

安装器先发现产品并生成逐项预览，再应用所选程序、Host、环境及 Skill 变更；保留知识库，变更前备份，更新检查现有哈希。运行程序需关闭后替换。

| 产品 | Host |
| --- | --- |
| E3D 2.1 | 2.1 / NET48 |
| E3D 3.1 系列 | 3.1.6 / NET48 |
| AM / PDMS | NET35 |

初始化查询 `Current Session`。REHASH 默认关闭，见[启动策略](startup-policy.md)。独立 MCP 禁用，统一用 [CLI](cli.md)。安装完成、进程创建、Host 核验分别验收；当前实机证据限 E3D2.1。

具体安装参数以仓库 `installer/INSTALL.md` 与安装器预览为准；不发布旧包、旧视频和历史设计副本。
