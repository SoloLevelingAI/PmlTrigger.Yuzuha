# 精简桌面设计与部署流程

## Why
用户要求树和 Ribbon 直接拖拽，右键有剪切复制粘贴且按需求分组；设计只展示当前 Tab，与部署穿梭框便捷切换，并明确加载、新建、完成到部署的步骤。Ribbon 按 Tab → Group → 按钮理解为可视化多级菜单。

## What Changes
- 树与 Ribbon 共享结构移动逻辑：Tab、Group 排序，按钮排序及跨 Group 移动。
- 应用内结构剪贴板支持延迟剪切、独立复制与重复粘贴；输入框继续使用系统文本剪贴板。
- 上下文菜单按对象分组，顶层可操作项最多七个。
- 主工作区采用设计、部署两个页签，设计只显示当前 Tab，复用部署页与模块选择。
- Ctrl+S 直接保存长期快照，文件加载合并 UIC/JSON 入口，项目 JSON 导出单列。
- 更新桌面说明文档与原生回归，实际 AVEVA 写入继续由用户确认。

## Impact
修改 WPF 客户端与相关原生验证、文档。独立后端 API、图像压缩、权限及持久记录规则保持一致。Group 排序限定所属 Tab；按钮可以跨 Tab 的 Group 移动。
