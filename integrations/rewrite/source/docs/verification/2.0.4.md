# 2.0.4 验证记录

日期：2026-10-19。

- 补齐窗口圆角、细外沿及激活状态颜色。Windows 11 保留系统合成窗口边框与阴影；旧系统通过 WPF WindowChrome 圆角处理。
- 保留非零系统边框，避免 WPF 创建窗口区域而使 Windows 11 原生圆角失效。透明分层窗口未启用。
- 最大化时隐藏装饰描边、使用直角，并按当前显示器工作区和 DPI 修正内容边距；还原后清除额外边距、恢复圆角。
- 新增 11 项窗口检查：原生圆角设置、无自定义窗口区域、边框颜色写入、四角裁剪、边框不拦截输入、四边缩放、标题拖动、最大化工作区与还原尺寸等。
- 70 项界面交互检查全部通过，三个尺寸、36 种页面状态布局通过，WPF 数据绑定错误为 0，Windows 凭据往返检查通过。
- 本次仅修改窗口呈现及对应验证；Core 与 Update 保留 2.0.3 已验证的实现。

实现参考：[Microsoft Windows 桌面应用圆角说明](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-rounded-corners)、[WPF WindowChromeWorker 源码](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Shell/WindowChromeWorker.cs)。
