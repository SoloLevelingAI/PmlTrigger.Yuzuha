# Spec Delta

## Purpose

把 LaunchDesk 的成熟交互和文件操作流程融入 Yuzuha 管理器，使工程启动、工具目录复制、备份和恢复在同一界面及命令行完成。通过同次操作记录连接预览与执行结果，并将入口进程创建、工程登录和 Host 可用分别呈现。

状态：候选，未 sync/archive。原型资料迁移、安装/工程发现、启动及文件/目录/ZIP/可选 7z 复制和条件恢复已接入管理服务，并有隔离子进程/合成载荷验证；未启动真实产品或更新真实工具。启动配置与工具复制分别作为独立 Feature 设计，GUI/CLI 状态与完整错误定位仍按未勾选任务验收。原型和当前源码见 [设计定位](../../design.md#现有源码与测试定位)，证据边界见 [实施验证](../../implementation-verification.md)。

## ADDED Requirements

### Requirement: 启动功能在管理器内完成

管理器 SHALL 集成产品发现、配置编辑、工程/模块选择、启动预览和执行，并在 GUI/CLI 使用相同快照。MUST 独立报告入口已创建、等待工程、工程已观察到和 Host 已核验；不得把创建进程视为登录或通信成功。

#### Scenario: 工程已启动但 Host 未就绪
- **WHEN** 启动入口返回成功且工程出现，但通信握手尚未成功
- **THEN** 保留启动成功记录，连接显示待核验，提供同一目标的测试入口

#### Scenario: 保存配置后不启动
- **WHEN** 用户仅保存启动配置
- **THEN** 只生成配置修订，不启动工程、不应用目录复制

### Requirement: 文件复制具有预览和恢复记录

管理器 SHALL 支持选定文件、目录和受支持压缩包的复制预览、应用、备份及恢复。执行 MUST 复核源/目标指纹，记录新增/覆盖/跳过项，拒绝路径越界与不明确覆盖；不把 AVEVA 工程数据库复制混入工具目录复制流程。

#### Scenario: 使用旧版支持的压缩包
- **WHEN** 用户选择 ZIP 或规划支持的 7z 工具包
- **THEN** 在执行前明确报告格式和解压依赖是否可用；支持时预览完整载荷，缺依赖时给出明确错误

#### Scenario: 目标在预览后被修改
- **WHEN** 外部程序改变即将覆盖的目标文件
- **THEN** 停止应用并保留源和修改后的目标，不使用过期计划继续覆盖

### Requirement: 所有执行结果可诊断

执行失败 SHALL 返回非空错误码、阶段、摘要和关联记录位置；发生部分应用时 MUST 报告实际完成项和恢复状态。密码等秘密不得写入预览、管理/通信 CLI 的命令行参数或记录。取消等待不得宣称已经终止 AVEVA 中发出的操作。

#### Scenario: 底层异常没有消息正文
- **WHEN** 文件复制或启动发生 Message 为空的异常
- **THEN** 仍返回明确失败状态、异常类型或错误码、失败阶段与记录位置，不返回空 Error
