LAUNCHDESK.NEXT / ENGINEERING LIBRARY

Concrete feature scripts and neutral logistics

Why

A maintainer should read the coordinator to see execution order, open one concrete C# script to see product behavior, and recognize OS/storage contracts as logistics.

What Changes

  • Group login input, public feature API, coordinator and concrete scripts under one feature.
  • Move Monitor/Marine arguments, discovery and licence policy into named scripts.
  • Replace feature-aware platform ports with neutral file, process, TCP, service and JSON capabilities.
  • Preserve saved-profile validation, secret ownership, evidence gates, observation and UI behavior.
  • Enforce the new boundary with ARC-07 and index actual source from DocFX.

Impact

No dependency changes, UI design changes or writes to the original project or Rewrite. Existing saved JSON fields and application data paths remain compatible.
