## 后续版本

原始快照不覆盖、不另存为、不重排、不清理元数据。收到新版本后新建日期与版本目录，保留原文件名，向清单追加来源、状态与实际哈希，再更新项目适配记录。若原稿状态以后由人工改变，应归档新的来源版本及依据，不能靠修改此处的 Draft 字段宣告评审通过。

DocFX 使用既有 C# 文档工具只读提取正文、表格和内嵌图片，生成可检索的阅读页；页码、排版、自动编号及完整结构以原始 Word 为准。生成页位于 artifacts，不手工同步第二份原文。构建会核对归档与发布副本的字节数和 SHA256；损坏、缺失或失效关联会失败。
