## Problems recorded — no repeated attempts or speculative fixes

1. **Array-return RPC query failure.** `!!YuzuhaReadCurrentElement(30,2,'')` failed once at 14:26:33.7397445Z; request `f693daad6819442f928c41f552ae4178`. A separate `!!YuzuhaRpcHost.methods()` array query failed once at 14:27:15.7456708Z; request `03994ce2ee9948518bb26bda7e9d4014`. Both returned Success=false, Code=PML_COMMAND_EXCEPTION, ErrorMessage=`PML list command or SIZE() query failed.`, Count=0, UnparsedCount=0, CLR 4.0.30319.42000. Ordinary command dispatch subsequently succeeded. The error does not distinguish expression assignment from SIZE lookup, so the cause is **not established** and neither PML function is marked untrusted.
2. **Module identity is Unknown.** Selection accepted Host.Model=`Unknown`. The inspected bootstrap constructs PmlCommandMethod but does not call RefreshModel. PID verification passed, but a meaningful Design/Model identity was not established. No module switch was attempted.
3. **RPC success is not the called method's boolean result.** `!!YuzuhaRpcHost.Log(!!FMSYS.SHOWNFORMS())` returned RPC Success=true/Code=OK without adding a log entry. GetLastLogError was subsequently captured by a separate string-array log: `ArgumentException: Unsupported PML array value: Aveva.Core.PMLNet.PMLNetAny`. Object-valued arrays are outside the recorder's current supported types. Callers must inspect Log/EndLog's return and GetLastLogError, not infer application success from transport dispatch success.
4. **Later text identifies the wrong gadget and reuses the Before time.** The inspected user log starts with PIPEEDITOR.NEWBRANCH but ends with PIPEEDITOR.NETTAILPOSITIONFRAME. The source loop overwrites gadgetStr and reuses time. Preserved, not silently fixed. DLL-generated phase UTC times remain distinct. Array values are sampled before the callback, not after it.
5. **Recorder exception handling conflates outcomes.** Existing `handle any` around callback evaluation also covers callbacks without return values. Its Later record does not establish callback success. BeginLog/EndLog errors are not consistently checked by this prototype wrapper.
6. **Chooser Cancel handler is empty.** Source defines `.hide()` with no action; calling it returned OK. This is a source-confirmed no-op, not a verified physical-button click. Cleanup used the explicit HIDE command. DeActivate's existing KILL/SHOW reset path was inspected but not executed.
7. **Knowledge retrieval returned no hits.** The requested project-method search returned `[]`; this is a retrieval observation, not proof that a database is corrupt. No index was rebuilt.

The prior file/function-name discrepancy is resolved in the user's current source: both wrapper definition and callback reference are YuzuhaGadgetDecorated.

## Coverage boundary

NET35 and NET48 automated tests cover sparse/nested arrays, Unicode, ordered append, nested event pairing, duplicate completion rejection, image deduplication, failure logging and real main/floating-window JPEG pixels. NET35 hosts compiled against AM/PDMS reference profiles. **AM/PDMS live sessions, multi-monitor/mixed-DPI E3D, module switching, reboot recovery, and model editing were not exercised in this live run.** These are coverage limits, not a claim that the tested recorder lacks validation.
