# AI 编写的 PML 草稿

按任务建立独立子目录，保存自己编写的 PMLFNC、PMLOBJ、PMLFRM 及复刻说明。避免使用用户工程内容作为公开夹具。默认不加入 AVEVA 的生产加载路径，不覆盖 PMLLIB/PMLUI。

提交进仓库的 PML 草稿会进入 DocFX 的 Script 自动发现范围，角色显示为 draft；发现不等于人工批准或可执行。机器本地的临时结果留在 artifacts。人工审核具体差异与版本后，再按批准范围迁移并保留回执。当前 GUI 评审迁移待接入。

原生窗口或工程状态验证应声明产品、模块、Host、命令、预期结果和不保存工程的退出步骤。PML REHASH、reload 与已加载版本验证各自记录结果，不将文件复制当作已加载。
