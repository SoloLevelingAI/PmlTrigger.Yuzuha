# 模块复用与命令登记压缩

本轮基线为 `e6a0d0d`，沿用 `codex/rewrite-semantic-compression` 分支。没有缩短变量名；变量改名仍只按 0.2 倍计权，空白变化不计收益。

| 结构 | 改造前 | 改造后 |
| --- | ---: | ---: |
| 应用、许可、工具的新建／保存／删除流程实现 | 9 份 | 3 份共享实现，3 次差异登记 |
| 三页的选择、草稿与上述三个命令声明 | 15 份 | 5 份共享声明，其余通过继承引用 |
| 相同的确定提交核验分支 | 3 份 | 1 份 |
| 涉及页面的公开快照读取实现 | 8 份 | 1 份 |

`DefinitionPageViewModel` 接收各页的定义构造、选择加载、保存恢复、确认文字与草稿订阅回调；未把不同页面的策略合并。保存前冻结旧实体身份；工具页仍强制重载保存后的选择。新建时的通知顺序、初始草稿不订阅、重复赋值仍订阅等行为保留。

`VerifyCommit` 只复用相同的核验协议：未确定结果不刷新、不解除待核验、不重放写入。设置页的无条件解除、其他页面的编号匹配解除、读取错误的提示顺序分别保留。登录编辑器需要原回执的 Profile 才确认成功，继续保持自己的独立分支。

代码投影文档采用共享契约引用：只有编译元数据明确声明实现同一接口方法、参数名及类型相同、文字完全一致时，才把实现中的参数／返回说明改为接口全文链接。源码 XML 注释、接口全文、实现摘要及实现特有说明保留；多契约、缺失契约或不同文字不合并。81 个方法的 258 项说明得到复用，259 个实际渲染链接逐一检查了页面和锚点，包含 DocFX 自动继承的一项。

| 投影重复说明的统计口径 | 之前 | 之后 | 减少 |
| --- | ---: | ---: | ---: |
| 相对本轮基线的 API 元数据重复非空白字符，包含参数和返回值 | 25,820 | 22,472 | 3,348（12.97%） |
| 同口径的多余出现次数 | 1,490 | 1,483 | 7 |
| 契约引用处理前后，真实 HTML 正文及参数／返回表的重复非空白字符 | 25,626 | 22,274 | 3,352（13.08%） |

最后一行在代码复用完成后、契约引用处理前取基线，用来单独验证投影复用的真实渲染收益；两种字符收益不能相加。统计对说明正文去除标记、解码实体并归一化空白，每种说明第一次出现之后的部分计为重复。导航、签名和编译器生成记录成员的套话不计。短引用仍会重复出现，所以重复字数减少明显多于重复次数。

源码成本也如实计入：生产 C# 不含注释和空白的词法字符由 315,215 降为 314,693，减少 522；含共享契约注释后的生产源码由 406,171 增为 406,878，净增 707。含新增回归测试的实现文件净增 4,617 个非空白字符；投影与审计工具另计。本轮整体源码没有净缩短，收益是减少独立维护的流程和说明副本。

UI 不在本轮改造范围。15 个视图、窗口、XAML、主题和页面文案文件逐一比对哈希不变；Roslyn 比对生产代码中 592 处中文字符串，内容及出现次数完全一致。没有修改产品或文档的布局、样式、图标与模板。原 WPF 绑定名保留，15 个继承属性在生成文档中可追踪到共享声明。

验证通过：72 项 .NET 测试、2 项投影规则测试、40 项隔离 WPF 按钮契约检查、完整 DocFX 构建与文档完整性检查。审计数据、前后快照及 Git 补丁位于 `artifacts/semantic-compression-round2/`。查看本轮 Diff：`git diff e6a0d0d..HEAD -- rewrite scripts/documentation-enrichment.mjs scripts/build-documentation.ps1`。

复算：`node rewrite/scripts/measure-compression.mjs e6a0d0d`；文档快照与比较使用 `rewrite/scripts/measure-projection-duplicates.mjs`，构建会自动运行共享契约链接校验。
