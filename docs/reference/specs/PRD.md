# PRD · 当前交付与待定

基线：正式 WPF / 原生 CLI。进入工程→选择并核验会话→部署/查询→回看记录；界面与 CLI 调用同一服务。

| 保留 | 完整操作 |
| --- | --- |
| 启动配置 | 产品/模块→组合筛选→差异→保存/重开→历史恢复；冲突留草稿 |
| 会话与读取 | 发现→选择→身份/协议核验→有界读取→原始回执 |
| PML 部署 | 源/目标计划→备份→加载→独立验证；未知先核验 |
| 本地资料 | 检索/正文/来源；个人笔记修订与资料管理 |
| 运行记录 | 状态/操作下拉＋文字取交集→详情/复制；空结果清详情 |
