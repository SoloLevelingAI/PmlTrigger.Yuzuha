## Ribbon 展开 / 收起（本轮重点）

- **展开 106 px（默认）**：文件 / 设计 / 撤销·重做 / 工具 四组，共 14 个命令入口，全部保留原有命令与大/小图标分组——加载文件、新建 UIC、保存快照；添加菜单页、添加 Group、添加按钮、检查项目、导出 UIC、导出项目 JSON；撤销、重做；部署 UIC、UIC ↔ XML、全部工具…。右侧保留「搜索命令 Ctrl+K」与收起按钮。
- **收起 44 px**：保留 Ribbon 页签与 5 个常用命令（加载文件、保存快照、撤销、重做、部署 UIC），右侧常驻「展开 Ribbon ▾」，Ctrl+F1 同步。
- 收起是**常见表格编辑工况**，不是窄屏补救：正常 1280 与紧凑 1100 各有自己的收起态，且与同尺寸展开态互为往返。
- 展开态不得压成一条文字菜单；任何状态下中央 UIC Ribbon 预览都不隐藏、不缩放。
- 旧布局若没有 `RibbonCollapsed` 字段，按**展开**处理；用户手动收起后写回布局，重启后按上次状态恢复（含两侧宽度与停靠位置）。

## 三个浮动工具（独立界面，轻外壳）

- **按钮 / 查找 980×680**：单条标题（工具名 + 当前 UIC / 选中项 + 停靠回主窗 + 并排 + 窗口控制）→ 搜索 / 作用域分段（当前 UIC / 已打开 3 个）/ 批量设置 / 筛选 → 结果表（按钮 · 来源 UIC、Macro、Tooltip，两行名称整块居中）→ 右侧详情（32/16 图标、唯一标识、显示、Group、Macro、Tooltip 预览）→ 底部反馈。
  - **作用域与结果一致**：当前 UIC 模式只列 `YtoolsAM.uic` 的 13 项且可批量；切到「已打开 3 个」才是跨文件只读定位，不出现隐含跨文件编辑。
  - **只勾选行、未选字段时主按钮是「批量设置 3 项」**，不是「应用到 3」；只有存在未应用字段时才允许应用。
- **UIC ↔ XML 1024×680**：XML 注册项列表 + 右侧单个 XML 详情。**登记对象是 UIC 文件而不是按钮**：详情写明「此 XML 登记到 YtoolsAM.uic（3 Group · 13 按钮）」，并注明按钮通过所属 UIC 间接关联、不存在 XML→按钮的直接引用。本页只读，登记写入在「管理登记」中单独确认。
- **部署 1024×720**：左侧 UIC 状态（待更新 / 只读 / 首次部署）+ 已关联 XML 只读列表（显示 5 / 9）；右侧统计、写入前核对、部署→登记分离、影响范围（13 个按钮 / 3 Group / 2 Tab）、校验结果。主命令是「预览写入…」，不出现立即写入。
- 三者都不复制主窗 Ribbon，也不叠加「工具标题 + 嵌套大标题 + 拖出条」。
