## Decisions
- 从统一 Changed 入口记录编辑前状态；比较内容后仅将实际变化入栈。移动与粘贴在修改前记录当前对象，供撤销恢复选中位置。
- 快照只包含 namespace、按钮定义及 Tab/Group/引用，不重复保存不可变原始 UIC XML；文档 ID、原始内容与部署绑定属于当前文档上下文，不参与编辑回放。
- 状态包含按钮 ID、sourceId、命令 Key、图标与大小。重做恢复原副本身份，不再次调用复制逻辑生成新 ID。
- 撤销与重做合计最多 50 步，按快照字符数另设约 16 MiB 上限；至少保留最近一步。会话栈不持久化，重启或加载/恢复文档重置，长期历史继续独立保存。
- 回放先等待在途保存结束（保存失败仍允许回退），停止定时器，替换编辑数据，推进 epoch 拒绝旧拖拽对象及部署缓存，重新解析选择并触发正常草稿保存。
- 回放清除待剪切对象，独立复制快照可继续使用。发生新的实际编辑时清空重做分支，无效拖放和自动保存不清空分支。
- Ctrl+Z/Ctrl+Y 在文本输入与组合框内交给原生控件；工具栏始终代表文档编辑撤销。部署页不执行设计撤销，部署写入期间保持现有锁定。

## Validation
原生隔离 WPF 回归覆盖三层排序、跨组移动、剪切/复制粘贴、多步往返、副本身份、分支截断、保存后回退、无效操作、元数据隔离、文本快捷键路由及容量限制。外部鼠标/键盘工具的窗口归属问题尚存，真实按键手感由运行窗口复核。
