# 从全项目到功能细节

全项目含9个产品／开发程序集、2个验证项目，后者不发布 API。项目看引用，模块跨层；目录按项目／类别／模块／搜索筛选，每页30项。

按当前名称翻页、显示位置并限制首尾；越界可返回。URL 保留页码／筛选用于返回、刷新、分享；跨项目接口与其他模块实现可见，共享端口的模块计数不相加。

View／ViewModel／交互支持分列。实现边取程序集，构造依赖取公开／受保护参数，交互关系取公开构造／强类型属性；不猜动态 XAML、私有调用、运行实例或次数。

外观仍支持浅／深／系统、蓝／紫／青绿、标准／紧凑；本机保存、同源同步并响应系统。窄屏浮层导航、表格内横滚；紧凑模式保留签名、注释、链接。

分类维护 `modules.json`，未命中先归通用职责并待审阅；图和目录由构建生成，不手改。见[维护](documentation.md)及[源码索引](~/artifacts/docfx/navigation/source-index/index.md)。
