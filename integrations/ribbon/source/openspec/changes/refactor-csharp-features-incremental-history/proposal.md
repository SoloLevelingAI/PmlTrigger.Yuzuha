# 按 Feature 重写 C# 后端并优化编辑性能

## Why
用户要求按 Feature 拆分并用 C# 重写，前后端职责独立且契约对齐；简单功能用脚本并附简短说明，仅在复杂或高度共用时抽接口/工厂。现有全量撤销快照与保存后全界面重建导致卡顿。截图红框经用户明确为浏览器式 Tab 或面包屑入口。

## What Changes
- 将正式 API 迁移至独立 C# 后端，保留 /api/v1、旧工作区 JSON 和部署记录。
- WPF 与后端分别按 Projects、Images、Uic、Workspace、Deployment、Management 拆分，Layout/Editing 仅属于前端。
- 两个 C# 进程编译同一份中性 DTO，显示计算属性移回桌面，网页保留对应 TypeScript 形状。
- 增量编辑日志仅记录受影响操作，规范化不替换对象图，去掉保存回调全量重绘；加图像缓存和按钮索引。
- 添加设计页 Tab 条及新建 Tab 入口，分隔大/小按钮列。
- 简单构建、启动、开发协调、架构检查和安装发现保留为脚本，提供每项少于八句的说明。

## Impact
默认启动 C# 后端；原 TS API 移至 tests/reference-api，原 TS 核心保留回归参考。工作区格式兼容，不删除文档或自动写真实 AVEVA 文件。本轮替代旧会话撤销的全量快照实现；50 步限制保留。
