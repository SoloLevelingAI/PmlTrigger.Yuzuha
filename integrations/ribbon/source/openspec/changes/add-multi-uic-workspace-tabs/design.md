## Document sessions
每个 UIC 的 DocumentSession 持有模型、选择、当前菜单页、独立增量撤销栈、修订号、脏标记与串行保存队列。工作区标签分为 document/deployment/modules，工具标签持有关联会话；图标与 DTO 不复制到每个编辑步骤。当前工作区复用设计视图，切换时保存/恢复会话；滚动、折叠与输入位置按文件保留。

## Async persistence
保存调用捕获明确文档及模型快照；响应只能更新该文档的 ID、状态与匹配修订的脏标记。编辑即时更新会话修订，因此在途旧保存不能清除新编辑。切换可后台保存离开的文件，关闭需成功记录；失败保持标签。主窗关闭等待全部会话，延迟调度实际关闭以避免 WPF Closing 重入。

## Tool views
旧实现将部署/模块工具页绑定每个文档；这一结构已被最新需求替代，不能继续作为目标架构。目标为用户手动打开的独立部署工具页，支持批量加入 UIC，列表项保存明确文档标识、修订与目标状态。模块及文件登记详情按需展开。预览和执行逐项核对文档、修订与目标，浏览或选择配置不会写真实 UIC/XML。

## Layout and naming
“UIC 菜单页”是文件内最终在 AVEVA 显示的 Tab，与顶部工作区文件标签不同。移除内部＋，添加菜单页仍在设计工具组。默认 1280×840，工具栏缩窄并按整组换行，小图标 16px 和文字左对齐，大图标 32px；两种选项完整显示。大量内容保留必要的滚动，避免缩小图标到不可读。

## FigCraft

## XML 加载登记与功能表格修订
