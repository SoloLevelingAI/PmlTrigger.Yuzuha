LaunchDesk 融合设计 v2
日期：2026-10-16

本版按反馈将 SeaGend 专用管理改为通用“工具与扩展”。
SeaGend 和 PML AI 为两个工具示例，其他自定义 PML 工具、程序和文件包也采用同一管理方式。
这次修改的是 FigCraft 原型；没有修改已安装应用、实际环境变量或许可配置。

本版新增与调整
1. 工具独立配置名称、分组、导入来源、部署目录和环境变量，登录配置可关联多个工具。
2. 导入来源支持压缩包、完整文件夹、单个或多个普通文件。完整文件包可直接选文件夹，无需先压缩。
3. 部署前预览文件映射；文件夹保留内部结构，普通文件可编辑目标相对路径。
4. 环境变量名称、值和作用范围可编辑。重命名预览关联项和外部脚本引用影响。
5. 作用范围包括仅启动进程、当前用户和系统。进程范围下次启动生效；用户和系统范围在显式保存应用后写入，系统范围按需提权。
6. 部署文件与应用环境变量分开执行。变量重命名不自动改写外部 PML / EVAR 脚本。
7. 保留原设计的多版本登录、独立许可监测、备份、失败恢复、回滚、分享和迁移。

查看方式
使用 FigCraft 打开 LaunchDesk-fusion-v2.figcraft。
可选择“LaunchDesk · 核心工作流”“工具导入与环境变量”或“小窗口 · 一屏操作”预览流程。
原型按钮只在设计页面之间跳转，不执行真实部署、环境变量写入、许可变更或 AVEVA 启动。
PNG 为单页预览，overview.png 为十个主要页面总览。

实现约定
以 WPF / .NET 10 为目标，复用现有管理器更新、比较、恢复和回滚逻辑，并补充通用工具模型与文件导入入口。
迁移需适配旧 .NET Framework 4.8 序列化与提权进程协议，回归文件更新和恢复测试。
原管理器记录按工具及目标关联，新融合配置采用独立工作空间，不覆盖原配置。
PML AI 路径、变量名和文件均为设计示例，不表示已在此电脑部署。
