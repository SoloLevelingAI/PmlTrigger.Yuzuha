# Feature 审查合并

真实 Claude Code CLI 的三个进程于 2026-10-30 16:26（Asia/Shanghai）几乎同时启动，全部正常完成。工具限制为 Read，不连接 MCP、不编辑文档。原始意见保存在本目录；所有最终设计写入由同一写入者通过 FigCraft 原生命令串行完成。

本表记录判断，不把子代理建议等同于用户要求。最终依据为本轮源文件与导出，原始评审图像属于首轮 0.12，部分问题在合并后已改变。

## Editor

| 评审意见 | 决定与结果 |
| --- | --- |
| 收起后部分命令不可找回 | 采纳：补更多命令浮层，保留展开入口；原型展示菜单，实际业务命令由 WPF 实现。 |
| 快捷栏与 Ribbon 重做状态矛盾 | 采纳：统一禁用表达，应用示例另外提供可撤销反馈。 |
| 个人常用应由 3+1 均摊为 2+2 | 否决：用户已确认 Ribbon 三行纵向填充，保留真实排布规则，不为了对称改成均分。 |
| 大/小图标预览像二选一，语言随窗口变化 | 采纳：两块均为普通预览，统一中文大小图标，不再表示互斥选中。 |
| 未保存点占关闭位 | 采纳：脏点与 × 分开，关闭位固定。 |
| 宽中心 Macro 与 Tooltip 间距过大 | 采纳：剩余列宽按比例分配，紧凑列保持最小宽度。 |
| 树父子项缩进不足 | 采纳：子项图标与文字进一步缩进，窄栏只省略长名称。 |

## Editing

| 评审意见 | 决定与结果 |
| --- | --- |
| 多行勾选后右栏作用域不清 | 部分采纳：保留活动单项与勾选集合两种独立概念，右栏标「单项」，活动行突出；批量设置进入明确字段面板。未强制把勾选后的单项编辑全部禁用，避免增加操作步骤。 |
| 跨文件结果混用 Group 与来源、缺活动行、定位重复 | 采纳：跨文件副行统一为文件 / Group，单行高亮对应详情，只保留一个主定位入口。 |
| 跨文件模式中当前文件应允许勾选 | 否决：与已确认「跨文件整体只读定位」冲突，避免同一表内混用编辑权限。 |
| 撤销仅静态文字，无具体内容 | 部分采纳：补明确的应用反馈和撤销入口，串起 Ctrl+Z/Ctrl+Y 示例；保留标题栏快捷方式与完整 Ribbon 中的命令，不因重复入口删除已确认命令。 |
| 标签统一，并按实际尺寸渲染所有图标 | 部分采纳：标签统一；表格的 16 px 图标用于紧凑列表，右侧独立展示大小图标资源，不在列表中放 32 px 大图破坏行高。 |
| Tooltip 三处都统一成两行 | 部分采纳：表格只显示正文，保持单行中心与密度；右侧详情分标题、正文，编辑表单提供两个字段，均属于同一 Tooltip 数据。 |

评审确认：首轮表格的双行名称上下余白一致，表头与单元格起点对齐。最终又进行了原生坐标审计。
