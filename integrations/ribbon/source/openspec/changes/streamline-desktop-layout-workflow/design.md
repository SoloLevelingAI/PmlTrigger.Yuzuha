## Context
原设计把所有项目 Tab 堆叠，部署使用独立模态窗口，右键混合文件、结构和属性操作。用户需要以多级菜单的直观方式编辑。

## Decisions
1. 用单一 PlaceSelection 操作服务树、Ribbon 拖放与剪切粘贴。移动只调整集合及引用位置，保留原 ID、sourceId、图标与大小；拒绝自投放、过期对象和无效层级。
2. 拖放使用进程内类型化 DataObject，并校验窗口及文档 epoch。提供位置线、区域高亮和目标说明；拖拽后抑制按钮点击，自动保存返回时不重建正在拖拽的控件。
3. 应用剪贴板保存不可变复制快照；每次粘贴生成新 ID、清空源标识和命令键，并一致重映射组内引用。剪切保留原对象，直到合法粘贴后才移动；切换文档取消待剪切。
4. 顶层菜单提供剪切、复制、粘贴及适用的添加、编辑、布局、删除。大小、移动目标、图标和标识放入子菜单。
5. 设计与部署采用主窗工作页。部署复用已有 HTTP 客户端窗口的内容与校验实现；同一文档修订内保留模块选择，编辑后重新获取部署快照。写入执行时阻止切换到设计或关闭主窗。
6. 手动保存为长期工作区快照，不强制弹出下载；UIC/JSON 导出是可选文件交付。

## Validation
原生 WPF 隔离回归覆盖集合与引用、剪贴板、单 Tab 渲染、部署复用和原有后端链路。外部 Windows 自动化仍受窗口归属识别异常限制，真实指针拖拽、任意 DPI 和输入法需要人工复核。测试只写模拟安装。
