# 功能表格界面视觉修订

## Why

`design/figcraft/uic-function-table.png` 只覆盖了一个页面，且视觉系统不统一：同一 Ribbon 行内 32px 与 16px 图标混用到失去主次、`新建 UIC` 与 `导出 UIC` 复用同一空方框图形、表格图标列 12 行重复同一占位方块、`显示` 列纯文本难扫读、工具条控件形态各异。用户要求用 FigCraft 把设计做全，并把对齐规范固化到 OpenSpec。

同时确认一条与上一轮相反的结论：**行末留白不是缺陷**，Ribbon 内容从左向右排列，末尾没有内容就自然结束，不拉伸、不整行居中。此前“整行居中”的建议作废。

## What Changes

- 交付一套 6 页 FigCraft 设计稿 `desktop-screens-v2.figcraft`：工作区、功能表格、批量设置弹层、部署 UIC、加载登记、768 紧凑布局；每页可单独导出。
- 统一外壳：标题栏、Ribbon、标签栏、面包屑、状态栏由同一段生成代码复用，页面差异只体现在主体区域。
- Ribbon：组内内容按内容块高度在内容带内垂直居中，组标题固定底部基线，每组右侧闭合分隔线，行末保留自然留白；紧凑宽度折叠为两组 + 「更多」。
- Ribbon 图标：32/16 双尺寸矢量族，统一描边与主色，按命令主次分配尺寸，消除同形复用；`导出 UIC`、`导出 JSON` 归回「文件」组，`检查项目` 独立成组。
- 标签栏：文档标签与固定页面（部署、加载登记）分离，页面不带关闭叉；激活标签白底 + 顶部 2px 主色条；脏标记为文件名前 6px 圆点。
- 表格：图标列改为每行语义图标（缺省 `—`）；`显示` 列改 pill；表头三态全选；列宽重分配、单元格 13px、行高 30；Tooltip 正文为次级色。
- 工具条与状态栏：搜索 / 筛选 / 主操作统一 30px 高与 6px 圆角，主操作实心；已选状态 chip + 清除；状态栏不再暴露调试地址。

## Impact

设计与规范层：新增 FigCraft 设计稿、生成脚本与总览图，更新 OpenSpec 记录。未改动 WPF 实现、后端 API、UIC 生成与权限逻辑；落地到桌面端需按本规范修改 `apps/desktop/Features/Editing/FunctionTable.cs`、`Views/Ui.cs`、`Resources/OfficeRibbon.xaml`。
