# 全项目、功能聚焦与主题验证

2026-10-20，在现有 DocFX 2.81.0 站点中加入项目与功能探索入口。

## 实现范围

- 十个重写项目的实际项目引用与职责概览；包含无公开 API 的验证项目。
- 九个可配置功能模块；同一端口允许被多个功能使用。模块规则维护于 `docs/reference/modules.json`，不移动源码或改写历史架构证据。
- 232 个类型、31 个接口；从编译元数据提取 34 条接口实现边、77 条公开或受保护构造依赖边，提供双向追踪。
- 按模块、项目、类别、功能描述及关联类型筛选。URL 保留关注范围，进入类型后可返回原目录；显式切回全局范围后刷新不会重新掉回原模块。
- 关联页显示跨项目契约；跨模块实现可展开。关系只表达静态声明与构造依赖，不声称证明运行时装配和调用次数。
- 外观控件提供浅色、深色、跟随系统，三种强调色与两种密度；恢复已保存偏好并同步同源标签页。

## 修复的问题

- 深色模式下顶部导航文字仍使用浅色主题的暗文字。
- 强调色改变后，部分链接因 RGB 变量未同步而保留默认蓝色。
- DocFX 高优先级布局规则使概览页仍保留右侧空栏，内容继续受到默认边距挤压。
- 390 像素窗口展开导航使固定页头达到约 407 像素；改为浮层后实测页头约 67 像素，页面未横向溢出。
- 默认跨文档动画在跳往未 opt-in 的 Scalar 页面时产生 ViewTransition 错误；站点使用稳定的跨页切换。
- 按 UseCases 等项目筛选时，另一个程序集中的接口关联不应被当前项目范围隐藏。

## 验证结果

完整执行 `scripts/build-documentation.ps1 -SkipRestore`，包括普通解决方案、可选 Aspire AppHost、元数据、网页与内容检查：零警告、零错误。原有 942 个公开声明、274 个公开方法说明和 82 个已审阅类型的文档覆盖保持通过。

`scripts/check-documentation.mjs` 核验所有类型和模块 URL、十个项目与架构白名单、实际 implements 关系、正反向实现及构造关联。

`scripts/check-documentation-browser.mjs` 共二十项检查通过，包括十一个页面视图和九项交互检查：

- 项目总览、接口/模型/枚举、功能模块及实时与静态 Scalar。
- 接口到实现、实现到契约、构造依赖跳转；模块与项目联合筛选；通过实现名反查接口。
- 返回原目录和刷新后的全局范围保留。
- 表格、折叠成员、全站搜索及原成员锚点。
- 1440、1024、768、390 像素布局与手机菜单。
- 真实外观控件、刷新后偏好恢复、系统模式变化及跨标签同步。
- 六种浅深与强调色组合的链接对比度至少 4.5:1；三种强调色实际产生不同链接颜色。

无页面脚本错误、资源请求失败或自动外网请求。`npm run review` 通过。

可复查结果在 `artifacts/docfx/verification.json`、`artifacts/documentation/functional-final-build.log` 与 `artifacts/documentation/browser/`。测试与预览继续使用隔离工作空间，本次未改变桌面业务代码。
