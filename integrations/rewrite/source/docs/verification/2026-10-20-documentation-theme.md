# 现代 DocFX 模板验证

2026-10-20，基于 DocFX 2.81.0 的内置 modern 模板添加仓库自有覆盖层。配置入口为 `docfx.json`，模板位于 `docs/reference/template/`。

## 展示与导航

- 统一系统无衬线字体、蓝色强调色、细边框、圆角和浅深主题；首页使用四个参考入口。
- 参数以名称、类型、说明三列表格呈现；返回值独立为紧凑表格。
- 属性、字段和事件集中到表格，保留类型、访问方式、职责及可展开完整定义。枚举显示成员与数值。
- 模型属性先于构造函数显示；记录的构造函数、辅助方法和运算符可展开查看。保留原始 UID、成员锚点和完整签名。
- 从实际元数据生成互斥分类：31 个接口、99 个数据模型、102 个实现类型，总计 232 个类型。命名空间页面仍可访问。
- 分类只调整文档导航，不移动 C# 源码或改变依赖。

## 实际验证

完整执行 `scripts/build-documentation.ps1 -SkipRestore`：普通解决方案、可选 Aspire AppHost、DocFX 元数据、网页生成和内容检查全部通过，零警告、零错误。942 个公开源码声明、274 个公开方法说明及 82 个已审阅类型的原有文档覆盖保持通过。

执行 `node scripts/check-documentation-browser.mjs`，包括：

1. 首页、接口、模型、枚举、接口目录、实时 Scalar、静态 Scalar 的真实资源加载。
2. 三列表格中的参数、模型十个属性及其类型说明。
3. 属性完整定义展开、折叠辅助成员的原锚点跳转。
4. 接口与模型分类分离、当前目录筛选、顶部导航和全站搜索。
5. 1440 × 1000、1024 × 768、390 × 844 窗口布局；窄屏表格在容器内滚动，页面不横向溢出。
6. 手机导航与深色模式。

共九个页面视图及五项交互检查通过，无脚本错误、HTTP 资源加载失败或自动外网请求。模型十个属性表格高度控制在 600 像素内；具体测量、结果与截图保存到 `artifacts/documentation/browser/`。`npm run review` 同样通过。

生成目录与临时预览使用隔离数据。本次修改限于文档配置、模板、导航生成与文档检查，未改变桌面业务实现。
