# 功能优先 UI 调整方案

> 该方案的“默认功能库、每文档三视图”已被用户纠正。当前以 `../global-workspace-tools/design.md` 的默认 Ribbon 编排与工作区单例工具为准；本文件保留前一轮设计历史。

## 用户确认与范围

2026-10-29：用户选择“先管理功能命令，再编排 Ribbon”。本变更优先调整编辑器使用方式。产品不变成通用流程编排器，也不把功能按钮的排列误作 Macro 执行依赖。

## 页面结构

标题栏 → 紧凑全局命令 → 文件标签 → 当前文件工作视图 → 内容 → 状态栏。

工作视图为“功能库 / Ribbon 编排 / 检查与部署”。它们不是三个新文档，也不是必须按序完成的步骤。切换保留每文件的选择、筛选、滚动和撤销栈。原先用户要求文件标签位于全局命令下方，这一关系继续保留；大型全局 Ribbon 改为紧凑命令区，待设计 Ribbon 只出现在编排预览中。

| 视图 | 主体 | 局部操作 |
| --- | --- | --- |
| 功能库（默认） | 定义表格 + 当前功能详情 | 新建、导入、批量修改、查看未放置、放入 Ribbon |
| Ribbon 编排 | 功能列表 + 原生 Ribbon 预览 + 放置属性 | 新建菜单页/分组、放入、移动、大小、移除引用 |
| 检查与部署 | 可定位问题列表 + 部署上下文与预览 | 返回问题、重跑检查、选择配置、生成预览、确认写入 |

功能库的单行主选择与复选批量集合区分；详情显示主选择，批量修改仅作用于复选集合。未放置是库存状态，允许保存。删除功能显示引用数量并列出影响；被引用功能必须显式处理引用，禁止静默删除。布局中的“移除引用”只删除当前 item，不删除定义。

## 数据与实现切入点

现有 Project.buttons 为功能定义，tabs/groups/items 为放置引用，沿用稳定 ID。第一阶段不迁移数据格式。名称、Macro、图标、Tooltip 在定义上维护，大小、分组和顺序在引用上维护。导入时保留共享引用关系与未编辑 XML；相同名称不能作为合并依据。

- Features/Editing/FunctionTable.cs：建立定义表格视图，以 buttonId 去重；引用位置另行查询，不能把“每个引用一行”直接当功能库。
- Features/Layout/WorkspaceActions.cs：复用预览渲染及未放置计算，提取功能库与放置选择的明确上下文。
- Features/Workspace/DocumentSessions.cs：保存每文档工作视图、主选择和批量集合。
- Features/Layout/LayoutEditing.cs 与 ContextActions.cs：区分新增定义、增加引用、独立副本和移除引用；现有增量撤销继续覆盖一次用户操作。
- Features/Deployment：复用真实部署计划、确认和备份。检查入口不得绕过后端校验。

功能库先限定当前文档。跨文件“复用”后续若加入，先采用显式复制生成新定义 ID，不承诺跨文件同步。Macro 在设计器内作为文本，不自动执行。

## 三条使用动线

1. 整理旧 UIC：导入 → 功能库检查 Macro/图标/提示 → 批量修改 → 查看受影响位置 → 保存。
2. 编排菜单：功能库勾选 → 放入 Ribbon → 选择菜单页/分组 → 调整顺序与大小 → 移除一个引用 → 撤销恢复。已有多个引用时不得把共享定义误拆成多个独立功能。
3. 交付：检查 → 定位并修复阻断问题 → 生成写入预览 → 核对完整目标路径和备份 → 显式确认。附加模块登记为单独操作，不与更新 UIC 混写。

## 视觉与适配

草案为 1280×840。功能库主表宽 842、详情宽 370，中间 20；编排列宽 242/650/308，中间 16。24 外边距，表格正文 13、操作 13、说明 12。大面积正文留给编辑，不用两套大 Ribbon 争夺视线。

这些是草案几何，不作为 WPF 固定坐标要求。实现采用可伸缩布局；窄窗口收起详情为抽屉，编排功能列表可收起，保留最小可读字号与局部滚动。键盘可完成放置与移动，不依赖拖放。

验收分成几何对齐、图形有效区域的光学对齐、视觉重量复核。间距、裁切、基线为可检查约束；视觉中心以工作内容区为参考，不要求整窗左右重量相等。需对 1280/1440/768 宽度及 100%/125%/150% DPI、长文本、空列表、多选、错误、禁用和焦点状态采样。视觉分数不能替代操作可达性或真实渲染。

## 2026-10-29 实施记录

WPF 现已实现功能库、Ribbon 编排和检查与部署三个工作视图，默认进入功能库；旧“当前交付与限制”段落保留设计阶段历史，不代表当前实现状态。当前程序为 `artifacts/desktop-command-first-0.6/RibbonStudio.Desktop.exe`，构建/启动脚本默认使用该版本。旧 0.5 产物保留。

功能库一行对应一个稳定定义；详情显式应用，待应用字段在切视图时保留并在保存/关闭/部署前提供保护。编排右侧仅维护引用位置、顺序和大小；功能名称、Macro、图标通过功能库维护。移除菜单页、分组或单个引用均保留功能库存。检查页显示当前修订的真实后端问题，过期结果不定位到新内容，更新 UIC 和模块登记继续进入既有独立工具页的预览确认流程。

新增 `CommandLibrary.cs`、`CommandPlacement.cs`、`CommandWorkspace.cs` 和 `CommandFirstVerification.cs`；原生验证包括真实详情输入/应用按钮、引用/撤销、多文档隔离、问题定位、未应用保护和九张视图截图。测量导航对齐与主表/详情边缘，不宣称几何检测已经解决光学平衡。当前最小窗口仍为 1050 DIP，768 与完整多 DPI 矩阵未完成。
